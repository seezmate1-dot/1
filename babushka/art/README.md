# Арт: стиль «уютная дача ночью»

Выбранный стиль — уютный стилизованный (как How to Fish, PEAK, Overcooked): мягкие скруглённые формы, рисованные текстуры, тёплые окна на фоне синей ночи. Бабушка круглая, в платке в горошек и круглых очках, с фонариком. Внук — «фасолина» в кепке.

## Что здесь

| Файл | Что это |
|---|---|
| `make_textures.py` | генерирует текстуры 1024×1024: обои, ковёр, крашеный пол, клеёнка, платок, вагонка, шифер, забор, брёвна бани, трава, земля, доски |
| `textures/` | готовые PNG (лицензия — наша, сделаны кодом) |
| `build_preview.py` | собирает дачу в Blender и рендерит два кадра |
| `renders/` | `exterior_night.png` — дача снаружи ночью, `gameplay_view.png` — игровой вид сверху со срезанными стенами |
| `dacha_preview.blend` | сцена Blender, можно открыть и покрутить |

## Как пересобрать

Blender ставится как Python-модуль (видеокарта не нужна, рендер Cycles на процессоре):

```
python -m venv blenv
blenv/bin/pip install bpy pillow
blenv/bin/python art/make_textures.py
blenv/bin/python art/build_preview.py          # финальное качество, около 10 минут
blenv/bin/python art/build_preview.py --quick  # быстрый черновик, около минуты
```

## Путь в Unreal

1. **Текстуры** импортируются в Unreal как есть. Материалы делаются через World Aligned Texture: так же, как в Blender, текстура ложится по миру и не растягивается на блоках разного размера.
2. **Мебель и постройки** (печь, сервант, кровати, баня, курятник, туалет) экспортируются из Blender в FBX с UV-развёрткой.
3. **Персонажи** в этом стиле делаются отдельно: модель бабушки и внука, авториг в Mixamo, анимации с Mixamo, ретаргет на скелет Unreal.

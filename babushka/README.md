# Бабушка накормит

Мемная кооп-стелс-комедия для 1–4 игроков: внуки ночью сбегают с бабушкиной дачи на дискотеку, а бабушка ловит их и кормит пирожками. Каждый пирожок делает внука толще и медленнее, а на пятом он превращается в колобка, который катится и сносит заборы.

- **Дизайн-документ:** [`docs/GDD.md`](docs/GDD.md) — механики, бабушка-ИИ, режимы, карты, техника, цена, продвижение, план.
- **Игра на Unreal Engine 5:** [`BabushkaGame/`](BabushkaGame) — проект на C++. Как установить и собрать: [`docs/SETUP.md`](docs/SETUP.md).
- **Веб-набросок:** [`web-sketch/index.html`](web-sketch/index.html) — та же механика в браузере, чтобы показать идею на телефоне.

## Управление

| Действие | Клавиатура | Геймпад |
|---|---|---|
| Ходьба | WASD или стрелки | левый стик |
| На цыпочках | Shift (держать) | левый курок |
| Взять, спрятаться, включить | E | A |
| Ещё ночь (после итогов) | R | Start |

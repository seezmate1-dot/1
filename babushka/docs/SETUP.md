# Установка и первый запуск

Всё делается на домашнем ПК. Если Unreal Engine, Visual Studio и Git уже стоят после проекта RPG, сразу переходите к шагу 4.

## Шаг 1. Компьютер

- 150 ГБ свободного места на SSD (движок около 60 ГБ, проект и кэш шейдеров меньше).
- Пока ОЗУ 16 ГБ: файл подкачки 32 ГБ на SSD (Пуск → «Настройка представления и производительности системы» → Дополнительно → Виртуальная память).
- Свежий драйвер видеокарты.

## Шаг 2. Unreal Engine 5

1. Установите **Epic Games Launcher** (unrealengine.com) и войдите в аккаунт Epic.
2. **Unreal Engine → Библиотека → +** и выберите последнюю версию 5.x (не Preview).
3. В **Параметрах** установки: «Templates and Feature Packs» — да, «Editor symbols for debugging» — нет.

## Шаг 3. Visual Studio и Git

1. **Visual Studio Community** с наборами «Разработка классических приложений на C++», «Разработка игр на C++» и «.NET», плюс последний Windows SDK. Версию берите ту, что Epic рекомендует для вашей версии движка (страница «Setting Up Visual Studio for Unreal Engine»).
2. **Git for Windows** и **GitHub Desktop**. В командной строке: `git lfs install` и `git config --global core.longpaths true`.

## Шаг 4. Проект

1. В GitHub Desktop: **File → Clone repository** → `grandma-will-feed-you`, путь короткий, например `C:\Dev\babushka`.
2. Правый клик по `BabushkaGame\BabushkaGame.uproject` → **Switch Unreal Engine version** → выберите установленную версию.
3. Двойной клик по `BabushkaGame.uproject` → на вопрос о пересборке модулей нажмите **Yes**. Сначала соберётся C++, потом редактор скомпилирует шейдеры (в первый раз до получаса).

Если появилось «could not be compiled»: правый клик по `.uproject` → **Generate Visual Studio project files**, откройте `BabushkaGame.sln`, выберите **Development Editor / Win64**, меню Сборка → Собрать решение и пришлите мне список ошибок.

## Шаг 5. Манекены и дача

1. В редакторе: **Content Drawer (Ctrl+Пробел) → + Add → Add Feature or Content Pack → Blueprint → Third Person → Add to Project**. Из пака нужны только манекены и их анимации: они временно играют внука и бабушку.
2. **Tools → Execute Python Script** → `C:\Dev\babushka\BabushkaGame\Content\Python\babushka_build_dacha.py`.
   Скрипт сам построит дачу из простых фигур (дом, забор, огород, курятник, баня, мебель, предметы, свет), расставит бабушку с маршрутом и подключит манекенов. В Output Log появится `Dacha built`.
3. Нажмите **Play** (Alt+P).

## Как играть

| Действие | Клавиатура | Геймпад |
|---|---|---|
| Ходьба | WASD или стрелки | левый стик |
| На цыпочках (тише, медленнее) | Shift | левый курок |
| Взять, спрятаться, включить | E | A |
| Ещё ночь после итогов | R | Start |

Цель: найти кроссовки в сенях и выбраться за забор до 05:00. Варианты: калитка (ключ в курятнике), лаз под забором слева (только худые, сытость 0–1), слабый забор справа (только колобок с разгона). Бабушку отвлекает сериал (телевизор в зале), с 01:00 до 02:30 она спит. Баня сгоняет один уровень сытости за 4 секунды.

## Что прислать мне

- номер версии движка;
- ошибки сборки, если были (текст или скриншот);
- скриншот игры и пара слов: что работает, что нет (видно ли бабушку и её фонарик, ходит ли она, ловит ли, кормит ли, превращается ли внук в колобка);
- если сцена слишком тёмная или светлая: в списке объектов выберите `PostProcess_Night` и поменяйте **Exposure Compensation** (больше — светлее).

Длина ночи для тестов 10 минут, меняется в **Edit → Project Settings → Game → Babushka → Night Seconds**.

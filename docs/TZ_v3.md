# Dark Fantasy Action RPG на Unreal Engine 5: мастер-промпт и ТЗ

*Версия 1 · локальная игра для одного игрока · архитектура готова к будущему MMO · только бесплатные ассеты*

## 1. Как пользоваться документом

Это рабочий промпт. Раздел 2 вставляется в начало каждого нового диалога с ИИ-помощником, после него добавляется промпт нужного этапа из раздела 12. Решения из раздела 3 не меняются без явного согласования.

## 2. Мастер-промпт (вставлять в начало диалога)

Ты senior-разработчик Unreal Engine 5 (C++ и Blueprint) и технический художник. Отвечай на русском.  
Мы делаем локальную реалистичную Dark Fantasy Action RPG для ПК. Архитектура должна быть готова к будущему переходу на мультиплеер/MMO: игровая логика построена серверно-авторитетно, данные отделены от визуала, всё data-driven.  
Правила:  
1. Только бесплатные ассеты и плагины. Для каждого ассета называй источник и лицензию.  
2. Ядро (компоненты, данные, бой) на C++, настройка, UI и прототипы на Blueprint.  
3. Код пиши полностью: с \#include, макросами UCLASS/UPROPERTY и указанием, в какой файл он идёт. Без заглушек и «...».  
4. Каждый этап: цель, список файлов, код, пошаговая настройка в редакторе, как проверить, типичные ошибки.  
5. Не добавляй функции вне текущего этапа. Если чего-то не хватает, предложи вариант и спроси.  
6. Цель по производительности: 60 FPS на RTX 3060 / 16 ГБ ОЗУ, 1080p.  
7. Не утверждай, что код работает, пока он не проверен: в конце этапа перечисли проверки, которые нужно выполнить в редакторе.  
8. Числа боя, дропа, цен и уровней бери из разделов 21–29 и 36–52 документа, не придумывай свои.

## 3. Принятые решения

- Сеттинг: тёмное фэнтези, средневековье, магия.

- Платформа: ПК (Windows), локально, один игрок.

- Движок: Unreal Engine 5, последняя стабильная версия на момент старта. В середине проекта движок не обновляем.

- Камера: от третьего лица.

- Бой: экшен с прямым управлением (удар, блок, уклонение). Таргет-система как в WoW включается в настройках как упрощение.

- Графика: реализм, Lumen, Nanite, Virtual Shadow Maps.

- Ассеты: только бесплатные, без покупок.

- Мультиплеер: не в первой версии, но код к нему подготовлен.

## 4. Бесплатные ассеты: что реально доступно

Важно: после 2024 года большая часть Megascans на Fab стала платной, бесплатной осталась курируемая подборка. Поэтому ставка не только на Megascans.

1.  **Fab, фильтр Price → Free.** Бесплатный контент Epic, включая персонажей и окружение Paragon и Infinity Blade (по духу близки к тёмному фэнтези). Плюс регулярные раздачи «Limited-Time Free»: заглядывай раз в месяц.

2.  **Megascans.** Бесплатные позиции на Fab и всё, что уже добавлено в твой аккаунт раньше (остаётся навсегда).

3.  **Poly Haven и ambientCG.** Текстуры, HDRI и часть моделей под CC0.

4.  **MetaHuman.** Лица и тела для героя и NPC. Перед релизом проверь актуальные условия лицензии.

5.  **Манекены Manny/Quinn** и анимации из шаблона Third Person. Для дополнительных анимаций Mixamo (бесплатно, нужен аккаунт Adobe), ретаргет через IK Retargeter.

6.  **Звук и музыка.** Бесплатное на Fab, CC0-пакеты, Freesound (лицензию проверять у каждого файла).

7.  **Sketchfab.** Только модели CC0 или CC-BY, с фильтром Downloadable.

**Правила учёта.** С первого дня ведётся таблица ассетов: название, ссылка, лицензия, нужна ли атрибуция. Ассеты Infinity Blade и Paragon старые: материалы проверяем на совместимость с Nanite и Lumen и при необходимости пересоздаём.

**Реалистичное ожидание.** Полного набора «герой, броня, монстры, замки» в одном стиле бесплатно не найти. Единый вид достигается общим освещением, цветокоррекцией и ограниченной палитрой (раздел 5).

## 5. Арт-направление

Настроение: мрачное, сырое, пасмурное, с редкими тёплыми источниками света.

- **Палитра:** холодные серо-зелёные и сине-серые тона. Акценты: тёплый огонь факелов и костров, золото магии.

- **Свет:** Directional Light + Sky Atmosphere + Volumetric Clouds, Lumen для GI и отражений, Exponential Height Fog с объёмным туманом.

- **Постпроцесс:** лёгкая виньетка, плёночное зерно, цветокоррекция через LUT, умеренный bloom, ограниченный auto-exposure.

- **Материалы:** PBR, текстуры 2K (4K только для героя и ключевых объектов), Virtual Textures для ландшафта, Runtime Virtual Texture для мягкого стыка камней и земли.

- **Ландшафт:** Landscape со слоями (грязь, мокрая трава, камень, снег). Деревья, камни и кусты расставляются через PCG.

- **Погода:** дождь и туман через Niagara, мокрые поверхности через параметр Wetness в материалах.

- **Персонажи:** MetaHuman-лица, броня из бесплатных паков, единая лёгкая десатурация для всех ассетов.

- **Дисциплина:** масштаб 1 unit = 1 см, референс-доска настроения, LOD у всех моделей.

## 6. Игровой мир (вертикальный срез)

Для полной игры: семь связанных регионов, каждый на своей карте World Partition (раздел 30). В первой версии строятся только Серая Топь и Увядшая Чаща (около 1×1 км), см. раздел 34. Регионы: Проклятый лес, Руины замка, деревня Серая Топь (хаб: торговец, кузнец, доска заданий), подземелье-склеп.

Старый черновик лора (заменён разделом 15): королевство пало после неудачного ритуала, лес заражён тьмой, герой последний из ордена Стражей.

## 7. Персонаж и анимации

- Создание героя: пол, 6–8 пресетов MetaHuman, имя. Полного редактора лица в первой версии нет.

- Движение: ходьба, бег, спринт, прыжок, перекат-уклонение, лестницы. Камера с коллизией и мягким следованием.

- Анимации: Blend Space и Animation Blueprint (Motion Matching, если позволяет версия движка), Layered Blend для верха и низа тела, IK ног. Оружие крепится к сокетам.

- Дополнительные анимации из Mixamo ретаргетятся на Manny через IK Retargeter.

## 8. Боёвка

- **Действия:** лёгкая атака (комбо из 3 ударов), тяжёлая атака (с зарядом), блок, парирование (короткое окно), уклонение с кадрами неуязвимости.

- **Ресурсы:** здоровье, выносливость, мана.

- **Попадания:** trace по сокетам оружия на анимационных нотифаях, hit-stop, реакции на удар, оглушение, смерть с ragdoll.

- **Магия:** 3 дара Угля: огненный снаряд, ледяной щит, исцеление. Они открываются у очагов, формулы в разделе 21.2, параметры в Data Asset.

- **Захват цели (настройка):** в меню «Геймплей» переключатель: Выкл (по умолчанию, свободный бой) / Мягкий (автоподбор цели в конусе перед героем) / Жёсткий (камера фиксируется на цели, смена цели кнопкой). Игра полностью проходима без захвата.

- **Враги:** увядший волк, одержимый охотник, корневая тварь и две элиты в Акте 1 (раздел 22.3). Нежить и культист-маг появятся с Акта 2. Behavior Tree + EQS, состояния: патруль, преследование, атака, отступление.

- **Баланс:** все числа в Data Table, без жёстко прописанных значений в коде.

## 9. Игровые системы

- **Статы:** Сила, Ловкость, Интеллект, Выносливость, из них считаются производные.

- **Инвентарь:** сетка или список, стеки, вес, слоты экипировки. Предметы это Data Asset с уникальным GUID.

- **Лут:** таблицы выпадения, 5 уровней редкости.

- **Квесты:** типы целей (убить, принести, поговорить, дойти), состояния, журнал, в первой версии 3 сюжетных и 5 побочных квестов.

- **Диалоги:** дерево реплик с условиями.

- **Торговля:** три торговца в хабе, бартер, выкуп и репутация (разделы 26–27). Простой крафт и улучшение оружия входят в первую версию (раздел 28).

- **Сохранения:** SaveGame, несколько слотов, автосохранение, версия формата.

- **Настройки:** графика (пресеты, DLSS/FSR/TSR), управление, звук, геймплей (захват цели, сложность, субтитры).

## 10. Архитектура (готовность к MMO)

- Модули: Core, Combat, Inventory, Quests, UI.

- Логика живёт в компонентах (HealthComponent, StaminaComponent, InventoryComponent, QuestComponent), а не в Blueprint персонажа.

- Способности и эффекты через Gameplay Ability System. Образец архитектуры: бесплатный Lyra Starter Game.

- Любое изменение состояния идёт через функции с авторитетом сервера (Server RPC, RepNotify уже в структуре), даже в одиночной игре. Для теста запускаем как Listen Server.

- Данные в Data Asset и Data Table, ссылки по GUID и Gameplay Tags.

- UI событийный (делегаты), без Tick там, где можно обойтись.

- Отдельный интерфейс Backend для будущих аккаунтов и облачных сохранений (в v1 заглушка с локальным файлом). Экономика (валюта, цены, торговля, обмен) тоже идёт через сервисы с авторитетом сервера и транзакциями, раздел 27.

## 11. Технические требования

- Проект: C++ на шаблоне Third Person. Плагины: Enhanced Input, Gameplay Abilities, Niagara, PCG, IK Rig, MetaHuman, Common UI.

- Контроль версий: Git + Git LFS с первого дня.

- Оптимизация: Nanite, Virtual Shadow Maps, World Partition с One File Per Actor, HLOD, Data Layers. Бюджет кадра 16 мс.

- Профилирование: Unreal Insights, stat unit, GPU Visualizer.

- Желательное железо для разработки: 32 ГБ ОЗУ, видеокарта класса RTX 3070 и выше, не менее 500 ГБ свободного SSD (проекты с Lumen и Nanite тяжёлые).

## 12. Этапы и промпты

Каждый промпт добавляется после мастер-промпта (раздел 2).

**Этап 0. Подготовка.** Готово, когда: пустой проект собирается, Git настроен, структура папок и настройки Lumen/Nanite применены. Промпт: «Создай структуру проекта UE5 C++ (Third Person), модули Core/Combat/Inventory/Quests/UI, настрой .gitignore и Git LFS, включи нужные плагины. Дай пошаговую инструкцию.»

**Этап 1. Персонаж и камера.** Готово, когда: герой бегает, прыгает, перекатывается, камера не проваливается в стены. Промпт: «Реализуй C++ класс персонажа с Enhanced Input, камерой с коллизией, анимациями передвижения и перекатом.»

**Этап 2. Боёвка.** Готово, когда: комбо, блок, парирование, уклонение и 3 заклинания работают, захват цели включается в настройках. Промпт: «Реализуй боевую систему на GAS: атаки с trace по сокетам, выносливость, попадания, три режима захвата цели.»

**Этап 3. Враги и ИИ.** Готово, когда: 3 типа врагов и 2 элиты ведут себя по состояниям, дают опыт и дроп по таблицам, умирают с ragdoll. Промпт: «Реализуй врагов с Behavior Tree и EQS, состояния патруль/преследование/атака/отступление, босса Мать Чащи по разделу 23.2 и элит по разделу 23.3.»

**Этап 4. Инвентарь, экипировка, лут.** Готово, когда: предметы подбираются, надеваются, влияют на статы, работают редкости и таблицы дропа (раздел 22), уровни и перки (раздел 25). Промпт: «Реализуй InventoryComponent, предметы как Data Asset с GUID, слоты экипировки, таблицы лута, UI инвентаря, а также опыт, уровни и перки по разделу 25.»

**Этап 5. Квесты, диалоги, NPC.** Готово, когда: проходятся 3 сюжетных и 5 побочных квестов, диалоги с условиями работают, торговцы продают, покупают и меняют предметы, работают бартер, репутация, крафт и улучшения (разделы 26–28). Промпт: «Реализуй QuestComponent, журнал, дерево диалогов по разделу 24, торговцев, бартер и обмен по разделам 26–27, крафт и улучшения по разделу 28.»

**Этап 6. Мир и атмосфера.** Готово, когда: карта собрана по регионам, свет, туман, погода и звук дают нужное настроение. Промпт: «Дай пошаговый план сборки ландшафта, материалов со слоями, PCG-расстановки и освещения под палитру из раздела 5.»

**Этап 7. UI, настройки, сохранения.** Готово, когда: HUD, меню, настройки графики и геймплея и сохранения работают. Промпт: «Реализуй HUD, главное меню, меню настроек (включая захват цели), систему сохранений с версионированием и достижения по разделу 29.1.»

**Этап 8. Полировка и сборка.** Готово, когда: 60 FPS на целевом железе, упакованная сборка запускается без редактора. Промпт: «Составь чек-лист оптимизации и упаковки сборки, найди узкие места по данным Unreal Insights.»

**Этапы 2б, 4б, 5б (версия 3).** Статусы и оглушение, масла и улучшения, охоты и малые системы. Условия готовности и промпты в разделе 52.2, привязка к этапам A0–A4 в 52.1. Локальный лог смертей (50.4) делается раньше остального, на этапе A0.

## 13. Чего нет в первой версии

Мультиплеер, обмен и аукцион между игроками, смена дня и ночи, редактор лица, ездовые животные, жильё игрока. Простой крафт и улучшения оружия в первую версию входят (раздел 28). Сознательно не делаем и не планируем (44.2): прочность оружия и брони, голод и жажду, перегруз по весу, ежедневные награды и таймеры, бесконечный реролл свойств.

## 14. Критерии готовности вертикального среза

- 60–90 минут игры: пролог, хаб, Увядшая Чаща с шахтой, мельницей и лагерем, босс Мать Чащи.

- 3 сюжетных и 5 побочных квестов, 3 типа врагов и 2 элиты, около 35 предметов.

- Стабильные 60 FPS на целевом железе, без вылетов.

- Таблица ассетов с лицензиями заполнена полностью.

**Примечание (версия 2).** Эти критерии описывают технический срез, этап A0 (раздел 43). Полный Акт 1 длится 6–8 часов и содержит больше врагов, квестов и мест (разделы 36–42).

## 15. Сюжет (заменяет черновик лора из раздела 6)

Рабочее название: **«Пепел Бледного Двора»**. Это предложенная основа: имена, твисты и концовки можно менять, структура и привязка к игровым системам останутся.

### 15.1 Логлайн

Тридцать лет назад король Альдрик Бледный купил бессмертие для своего рода у существа, запертого под столицей, и страна начала гнить. Игрок просыпается среди пепла часовни Стражей с углём чужого огня в груди и без памяти. Чтобы понять, кто он, ему придётся собрать три Печати и решить судьбу короля, магистра и самого древнего пленника.

### 15.2 Предыстория мира

- **Королевство Каэр-Морн.** Богатая страна лесов, замков и торговых дорог. Сорок лет назад её накрыла Серая Лихорадка.

- **Орден Стражей.** Рыцари-маги, которые веками удерживали под столицей существо, называемое Безымянным (Пустота). Печати на нём ставил Орден.

- **Ритуал «Вечная Корона».** Король и придворный маг предложили Безымянному сделку: бессмертие королевскому роду в обмен на жизнь земли. Орден воспротивился, но проиграл.

- **Итог.** Королевский род стал нежитью (Бледный Двор), лес превратился в Увядшую Чащу, а Печать, державшая Безымянного, раскололась на три осколка. Каждый осколок хранится в своём месте.

- **Серая Топь.** Последняя деревня у границы Чащи. Староста Годрик тайно платил Двору данью, чтобы деревню не трогали.

### 15.3 Главная тайна и «Уголь памяти»

Орден создал двенадцать сосудов с огнём очагов, «Углей». Герой носит последний. Уголь даёт ему магию (огонь, лёд, исцеление) и возвращение после смерти, но за это забирает память.

**Связь с игровыми системами:**

- **Очаги Стражей** это точки сохранения. Отдых у очага восстанавливает здоровье и воскрешает обычных врагов.

- Каждый новый очаг показывает короткое воспоминание (3–8 секунд, кадры и закадровый голос). Так сюжет раскрывается постепенно.

- Смерть возвращает героя к последнему очагу, и мир рассказывает, что Уголь забрал ещё кусочек.

**Скрытая правда.** Герой был учеником Магистра Эйлвина. Он погиб, пытаясь украсть первую Печать по приказу учителя. Эйлвин вернул его Углём, а память стёрлась как побочный эффект. Магистр не рассказывает об этом: ему нужны три Печати и Уголь, чтобы самому надеть Корону.

### 15.4 Структура: пролог и три акта

**Пролог «Угли» (10 минут).** Герой приходит в себя в сожжённой часовне. Игрок выбирает имя и внешность. Обучение: движение, уклонение, лёгкая и тяжёлая атака, блок. Первый бой с увядшими волками, первый очаг, дорога в Серую Топь.

**Акт 1 «Серая Топь» (основа первой версии).**

- Деревня осаждена. Травница Мара лечит раненых и первой замечает Уголь в груди героя.

- Хаб: торговец, кузнец Торгрим, доска заданий, дом старосты.

- Цель: найти Печать Леса в Увядшей Чаще.

- Путь: Чаща (лагерь охотников, заброшенная шахта, мельница, необязательно дом Эльзы с цепочкой из лунника), затем логово Матери Чащи.

- **Босс: Мать Чащи.** Бывшая травница Эльза, жена старосты и мать Мары: больная лихорадкой, она была отдана Двору и превращена в хозяйку леса. Две фазы: корни и шипы на дальней дистанции, затем ближний бой с рывками.

- После боя к герою прилетает ворон с письмом Эйлвина: «Ты справился. Следующая Печать в руинах Каэр-Мора».

**Акт 2 «Тарвен и руины» (кратко, подробно в разделе 31).**

- Разрушенный замок, архивы Ордена, призрак королевы Исольд.

- **Босс: Гарет Железный Обет.** Капитан Стражей, павший вместе с Орденом. Его доспех проржавел и срастается с телом.

- Воспоминания открывают прошлое героя. Исольд предлагает другой путь: не собирать Печати, а вернуться к Безымянному и спросить его.

- **Ключевой выбор:** отдать две Печати Эйлвину (он ждёт у ворот) или оставить себе.

**Акт 3 «Горы, Подгород, Склеп» (кратко, подробно в разделе 31).**

- Королевские склепы, рыцари Бледного Двора, лестница вниз к Безымянному.

- **Босс: король Альдрик.** Первая фаза: меч и щит. Вторая фаза: он призывает Двор и черпает силу из Безымянного.

- Эйлвин появляется в финале и требует Корону либо нападает, если ему отказали.

- Финальный выбор определяет концовку.

### 15.5 Концовки

- **«Пепел».** Герой гасит Уголь и Печати, Безымянный умирает, проклятие спадает. Герой тоже: он больше не держится огнём. Страна медленно оживает. Печальная, но чистая концовка.

- **«Корона».** Герой надевает Корону сам. Лес отступает, но он становится новым бессмертным стражем без памяти и срока. Двусмысленная концовка.

- **«Свобода».** Герой освобождает Безымянного. Тот уходит, лес меняется непредсказуемо, Бледный Двор рассыпается. Открытая концовка.

- **«Серый Магистр».** Если герой отдал Печати Эйлвину и не остановил его в финале, Магистр надевает Корону. Плохая концовка.

На выбор влияют три решения: отдать ли Печати Эйлвину, что сказать старосте Годрику про дань, и как поступить с Исольд.

### 15.6 Побочные квесты (5 для первой версии)

1.  **«Дань старосты».** Герой находит доказательства, что Годрик платил Двору. Выбор: разоблачить (деревня теряет доверие к старосте, торговец поднимает цены) или промолчать (староста становится должником).

2.  **«Холодное железо».** Торгрим просит принести 10 ржавого железа из заброшенной шахты. Мини-подземелье с ловушками. Награда: уникальный меч.

3.  **«Потерянный дозор».** Найти пропавших стражников. Находки: письма и записки, раскрывающие, как давно деревня платит дань.

4.  **«Колокол часовни».** Вернуть колокол. Его звон днём ослабляет туман в Чаще и показывает скрытые тропы.

5.  **«Дочь мельника».** Девочка пропала в лесу. Исход зависит от того, как быстро герой пришёл. Эмоциональный квест без боя.

### 15.7 Тон, подача, правила диалогов

- Мрачно, но не безнадёжно. Юмор только сухой, у Торгрима.

- Мало слов, много окружения: записки, барельефы, руины, поведение NPC.

- Реплики короткие. Нет длинных монологов, лор раскрывается предметами, записками и воспоминаниями.

- В выборах нет «правильного» ответа: каждый чем-то платит.

- Подача: диалоги, воспоминания у очагов, записки, 3–5 коротких кат-сцен на Sequencer. Закадровый голос в первой версии либо текстом, либо бесплатным синтезом речи.

### 15.8 Что входит в первую версию

Пролог, Акт 1 целиком (деревня, Увядшая Чаща, босс Мать Чащи), 12 побочных квестов (раздел 42), 6 очагов (раздел 37), по одному воспоминанию у каждого очага. Длительность и состав полного Акта 1 описаны в разделе 37. Акты 2 и 3 пишутся и собираются отдельными этапами после проверки боёвки и атмосферы.

## 16. Персонажи и подбор ассетов

**Честная оговорка.** Герои Paragon выглядят как стилизованные «геройские» модели из MOBA, а не как фотореализм. MetaHuman реалистичнее, но бесплатной средневековой одежды и брони для него мало. Поэтому в проекте два типа персонажей: люди (MetaHuman) и «большие» фигуры (боссы, нежить, герои Paragon с переработанными текстурами). Смешение стилей сглаживается общей цветокоррекцией и перетекстуровкой.

Лицензионный факт: бесплатные ассеты Paragon разрешено использовать, \<u\>пока проект сделан на Unreal Engine\</u\>. Они выпущены под UE4, поэтому их нужно конвертировать в UE5 и ретаргетить на скелет Manny.

### 16.1 Ключевые персонажи

**Герой (игрок), «Последний Страж».**

- Облик: MetaHuman, 6–8 пресетов лица, шрамы и пепел текстурами. Мужской и женский варианты.

- Броня: собранная из Paragon-деталей (кандидаты: Steel, Greystone) и перетекстурованная в тёмную сталь с углями на швах. Это самый трудоёмкий кусок арта.

- Облик: MetaHuman + простая льняная одежда. Одежду придётся делать в Blender или искать на Fab.

- Роль: лечит, продаёт зелья, объясняет Уголь.

**Торгрим Каменная Рука, кузнец.**

**Годрик, староста.**

- Облик: MetaHuman, пожилой.

**Магистр Эйлвин, наставник и главный антагонист.**

- Высокий, седой, мягкий голос, серая мантия Ордена.

## 21. Боевая математика и сложности

### 21.1 Параметры игрока (уровень 1)

- **Характеристики:** Сила 10, Ловкость 10, Интеллект 10, Выносливость 10. За уровень даётся 3 очка.

- **Здоровье** = 60 + 4 × Выносливость (100 на старте). **Выносливость (запас сил)** = 80 + 2 × Выносливость (100). **Мана** = 30 + 2 × Интеллект (50).

- **Фляга пепла:** 3 заряда, лечит 40% здоровья, заряды восстанавливаются у очага. Улучшение у Торгрима даёт до 5 зарядов в первой версии (цены в разделе 28).

- **Вес:** лимит переноски = 100 + 3 × Сила (130 на старте). Вес есть только у оружия, щитов и брони. Перегруза и штрафов нет: если места не хватает, предмет не подбирается (раздел 50.3).

### 21.2 Формулы урона

- **Базовый урон** = урон оружия + 0,5 × Сила (для лёгких клинков 0,5 × Ловкость).

- **Итоговый урон** = базовый × множитель удара × множитель крита × 100 / (100 + броня цели).

- **Множители ударов:** лёгкий 1-й 1,0, 2-й 1,1, 3-й 1,4. Тяжёлый 2,0 (с зарядом 2,8). Удар после спринта 1,3. Добивание после парирования 3,0.

- **Крит:** шанс 5% + 0,3% за каждое очко Ловкости сверх 10, множитель 1,5.

- **Стартовое оружие:** меч, урон 15 (итог около 20 за удар). **Награда с первого босса:** Клинок Корней, урон 28.

- **Расход выносливости:** лёгкий удар 15, тяжёлый 28, перекат 20, спринт 8 в секунду. Регенерация 25 в секунду после паузы 1 секунда.

- **Блок:** гасит 80% урона, тратит выносливость, равную 0,6 от поглощённого урона. При нуле выносливости щит ломается, герой оглушён на 1,5 секунды.

- **Парирование:** окно 0,20 секунды на нормальной сложности. Успех оглушает врага на 1,5 секунды и открывает добивание.

- **Перекат:** 0,6 секунды всего, из них 0,35 секунды неуязвимости.

- **Заклинания (дары Угля):**

  - Огненный снаряд: 25 + 1,2 × Интеллект, мана 15, перезарядка 1,5 секунды, игнорирует броню.

  - Ледяной щит: поглощает 60 + 2 × Интеллект урона на 8 секунд, мана 20.

  - Исцеление: 20% здоровья за 4 секунды каста, мана 25.

  - Мана возвращается: +3 за каждый удар по врагу.

- **Доспехи героя:** броня 10 на старте, около 40 после снаряжения Акта 1. Снижение урона: броня 10 даёт 91% входящего урона, броня 40 даёт 71%.

### 21.3 Три уровня сложности

- **«Путник» (лёгкая).** Здоровье врагов ×0,7, урон врагов ×0,6, окно парирования 0,35 с, неуязвимость переката 0,45 с, фляг на 2 больше, при смерти потерь нет, телеграфы ярче.

- **«Страж» (нормальная, по умолчанию).** Всё ×1,0, окно 0,20 с, неуязвимость 0,35 с, фляг 3, при смерти теряется 10% золота.

- **«Пепельный» (сложная).** Здоровье врагов ×1,4, урон ×1,5, окно 0,15 с, неуязвимость 0,30 с, фляг на 1 меньше, при смерти теряется 25% золота (один раз можно вернуть на месте гибели). Боссы быстрее на 10% и добавляют по одной атаке в комбо. Шанс редких предметов ×1,25.

- Сложность меняется у очага вне боя. Захват цели (раздел 8) включается отдельно в настройках и от сложности не зависит.

## 23. Боссы: механики, арены, визуальные атаки

### 23.1 Единый визуальный язык атак

Игрок должен понимать любую атаку по цвету и звуку ещё до удара. Эти правила действуют для всех врагов и боссов.

- **Жёлтая вспышка** на оружии или теле (0,3 с): атаку можно парировать или заблокировать.

- **Красная подсветка** (линия, круг или конус на земле): нельзя блокировать и парировать, нужно уклоняться. Область подсвечена заранее.

- **Зелёный или фиолетовый** дым и свечение: магическая или ядовитая зона. Наносит урон со временем.

- **Белая вспышка** перед рывком к игроку: захват, нужно уклоняться.

- **Время замаха:** быстрая атака 0,5 с, средняя 0,9 с, тяжёлая 1,4 с.

- **Звук:** уникальный свист перед красной атакой, глухой гул перед тяжёлым ударом.

- **Отклик попадания:** тряска камеры 0,15 с на тяжёлых ударах, остановка кадра (hit-stop) 0,05 с, при смерти босса замедление времени до 0,3 на 2 секунды.

- **Эффекты:** Niagara для корней, шипов, спор и волн. Заранее готовятся Decal-материалы для красных зон и общий материал свечения оружия.

### 23.2 Босс 1: Мать Чащи (полная спецификация, первая версия)

- По краю шесть корневых колонн. Две из них разрушаются от ударов босса и служат укрытием от спор.

- Приземный туман, холодный сине-зелёный свет, четыре костра по краю дают тёплые пятна.

- Вход через завесу тумана. Очаг прямо перед вратами, новый очаг появляется в центре после победы.

**Параметры (сложность «Страж»).** Здоровье 2400, броня 40, запас оглушения 150 (чем он заполняется, раздел 46). Огонь ×1,5, лёд (стужа) ×0,8. Яд и увядание не действуют, кровотечение сопротивляется, пороги статусов ×3 (раздел 45.3).

**Фаза 1 (100–50% здоровья).**

- **Хлёст корнем** (жёлтая вспышка): дуга 90°, дальность 8 м, урон 30, замах 0,9 с. Парируется.

- **Двойной хлёст:** два удара подряд, урон 30 и 36, замах 1,2 с.

- **Споровое облако** (зелёный шар): облако радиусом 5 м на 10 секунд, урон 5 в секунду и замедление 20%. Огненный снаряд выжигает облако.

- **Призыв волков:** каждые 30 секунд два увядших волка.

**Фаза 2 (50–0%), атаки быстрее на 10%.**

- **Рывок** (красная линия 15 м): урон 45, не блокируется. Если игрок уклонился, босс врезается в колонну и оглушён на 4 секунды. Корневое «сердце» на спине открыто, урон по нему ×1,5.

- **Корневая клетка** (красный круг вокруг игрока): через 1,2 с замыкается, обездвиживает на 2 секунды, урон 20 в секунду. Своевременное уклонение вырывает героя.

**Ожидаемый бой.** 4–6 минут, с огненным маслом 3–4,5 минуты (47.3). Герой уровня 8 получает 8–12 попаданий при нормальной игре, 3 фляги это покрывают.

**Награды:** раздел 22.5. Если у героя есть «Цепочка из лунника», на 15% здоровья доступно действие «Показать цепочку»: бой заканчивается мирно, Печать отдаётся добровольно, награда та же и VillageTrust +10 (сцена 4 в разделе 32.3).

## 24. Диалоги и ветки персонажей

### 24.1 Устройство диалоговой системы

- **Узлы:** реплика NPC, выбор игрока (до 4 вариантов, один всегда «закончить разговор»), условие (флаг, репутация, квест, характеристика), эффект (флаг, предмет, золото, репутация), проверка навыка (порог Силы или Интеллекта).

- **Хранение:** Data Asset «DialogueGraph», идентификаторы через Gameplay Tags, ключи локализации у каждой реплики.

- **Правила текста:** реплика до 140 символов, не больше четырёх реплик подряд без выбора. Озвучка добавляется позже без правки логики.

- **Подача:** камера мягко приближается к собеседнику, игрок может пропустить реплику, журнал хранит последние диалоги.

### 24.2 Переменные сюжета

- **VillageTrust** (0–100, старт 50): доверие деревни к герою. Влияет на цены и доступные квесты.

- **AlwinTrust** (0–100, старт 70): доверие Эйлвина. Растёт, если игрок выполняет его просьбы.

- **IsoldeBond** (0–100, старт 0): связь с призраком королевы.

- **GodrikTributeRevealed**, **GaveSealsToAlwin**, **MillerDaughterSaved**, **BellRung** (флаги).

- **HearthMemoriesSeen** (0–12): число увиденных воспоминаний у очагов. Открывает фрагменты правды.

### 24.3 Как решения меняют персонажей

- **«Дань старосты».** Разоблачить Годрика: VillageTrust −15, Годрик теряет должность, цены у торговцев растут вместе с падением VillageTrust (раздел 26), но Мара открывает редкие рецепты. Промолчать: VillageTrust +5, Годрик даёт ключ от склада с эпическим предметом. В Акте 2 тайна всплывает всё равно, и Мара холодеет к герою.

- **«Дочь мельника».** Спасена: VillageTrust +10, мельница становится безопасной зоной с очагом. Не спасена: VillageTrust −10, позже в Чаще появляется скрытая сцена с тенью девочки.

- **Печати Эйлвину (Акт 2).** Отдал: AlwinTrust +30, Мара и Торгрим перестают помогать, Исольд закрывается. Оставил: AlwinTrust падает, Эйлвин в финале становится врагом.

- **Исольд.** Если игрок слушал её рассказы, IsoldeBond растёт и в финале открывается концовка «Свобода».

### 24.4 Роли персонажей по актам

- **Мара:** Акт 1 союзница и лекарь. Акт 2 передаёт совет через ворона. Акт 3 может прийти в склеп, если VillageTrust выше 70.

- **Торгрим:** остаётся в деревне, улучшает оружие. В Акте 2 присылает чертёж оружия под Гарета, если герой не отдавал Печати Эйлвину.

- **Годрик:** Акт 1 даёт квесты и скрывает правду. После разоблачения уходит из деревни или остаётся тихим соратником.

- **Эйлвин:** письма, вороны, воспоминания. Лично появляется в конце Акта 2 и в финале.

- **Исольд:** Акт 2 и 3, призрак в архиве и склепе.

- **Гарет, Альдрик, Мать Чащи:** боссы с короткими предсмертными репликами, раскрывающими лор.

## 25. Система уровней и развитие

### 25.1 Опыт и уровни

- Суммарный опыт для уровня L равен 75 × L × (L − 1). Переход с уровня n на n+1 стоит 150 × n.

- **Порог опыта по уровням:** 2 — 150, 3 — 450, 4 — 900, 5 — 1500, 6 — 2250, 7 — 3150, 8 — 4200, 9 — 5400, 10 — 6750, 11 — 8250, 12 — 9900, 13 — 11700, 14 — 13650, 15 — 15750.

- Максимальный уровень первой версии: 15. В полной игре планируется 30 с той же формулой.

- Уровень повышается автоматически при получении опыта. Очки распределяются в меню вне боя.

### 25.2 Очки характеристик и перки

- **3 очка характеристик** за каждый уровень, начиная со второго (всего 42 к 15 уровню). Предел одной характеристики: 40.

- **Очко перка** на уровнях 3, 6, 9, 12 и 15 (всего 5). Перки делятся на три ветви по три перка, выбрать можно 5 из 9:

  - **Клинок:** «Крепкая хватка» (+10% урона тяжёлых ударов), «Выверенный удар» (окно парирования +0,05 с), «Кровь Стража» (убийство лечит 3% здоровья).

  - **Щит:** «Стойкость» (блок поглощает 85% вместо 80%), «Второе дыхание» (регенерация выносливости +15%), «Железная кожа» (+10 брони).

  - **Уголь:** «Жар» (огненный снаряд +20%), «Холод» (ледяной щит поглощает на 25% больше), «Искра» (мана за удар +5 вместо +3).

- **Сброс.** Первый бесплатно у Мары, дальше 100 × уровень героя в монетах. Возвращает все очки характеристик и перков.

### 25.3 Требования к снаряжению

- Предмет требует минимальный уровень героя и значение характеристики (Сила, Ловкость или Интеллект).

- Минимальный уровень по редкости: обычный 1, необычный 3, редкий 5, эпический 8, легендарный 12.

- Пример: Клинок Корней (редкий) требует уровень 5 и Силу 12.

### 25.4 Уровни врагов и зон

- Уровень врага фиксирован и нужен только для штрафа опыта (раздел 22.4) и значка опасности в интерфейсе. Характеристики врагов от уровня героя не меняются.

- **Уровни:** волк 2, охотник 4, корневая тварь 6, капитан охотников 6, корневой страж 7, Мать Чащи 9.

- **Зоны:** волчья тропа 1–3, мельница 3–5, охотничий лагерь 4–6, шахта 5–7, логово Матери Чащи 8–9.

- Значок опасности красный, если враг выше героя на 3 и более уровня, серый, если ниже на 3 и более.

## 26. Экономика, рынок и торговцы

### 26.1 Валюта и цены предметов

- Валюта: **монеты**. Материалы валютой не являются, но продаются.

- **Базовая стоимость по редкости:** обычный 20, необычный 60, редкий 200, эпический 700, легендарный 2500.

- **Материалы и расходники:** волчья шкура 8, клык 25, ржавое железо 12, сухой корень 10, трава 6, холодное железо 60, смола 10, споровый мешочек 12, иней 15, зелье исцеления 40, зелье выносливости 40, противоядие 30, склянка 5, стрела 2. Смолу, мешочки и иней торговцы не продают, только покупают. Масла не продаются и не покупаются (47.2).

- Квестовые предметы не продаются.

### 26.2 Формулы цен

- **Продажа игроком:** 0,30 × базовая стоимость.

- **Покупка у торговца:** базовая стоимость × (1,2 − 0,004 × VillageTrust). При доверии 50 множитель 1,0, при 0 это 1,2, при 100 это 0,8.

- **Инвариант:** цена покупки всегда не ниже 2,67 цены продажи того же предмета. Так нельзя заработать, купив и продав.

- **Выкуп:** последние 10 проданных предметов можно вернуть за ту же сумму, за которую они проданы.

### 26.3 Торговцы

- **Торгрим (кузнец):** оружие и броня обычного и необычного качества всегда, улучшения, покупает оружие, броню и металл. Запас монет 400, +100 за каждый отдых у очага, максимум 600.

- **Мара (травница):** зелья, склянки, травы. Рецепты не продаёт, а учит (50.1). Покупает травы, зелья и материалы. Запас 300, +80 за отдых, максимум 500.

- **Брик (странствующий торговец):** новый персонаж, стоит у дороги после пролога. Продаёт расходники и стрелы. Каждые 3 отдыха меняет 3 редких предмета по таблице зоны, раз в 10 отдыхов предлагает один эпический предмет по цене в 1,5 раза выше базовой. Запас 600.

- Если у торговца не хватает монет, он предлагает обмен предметами или отказывается. Это не даёт скупить всё подряд ради фарма.

### 26.4 Репутация и торговля

- VillageTrust (раздел 24.2) меняет цены по формуле из 26.2.

- При VillageTrust от 70 Мара бесплатно учит редким рецептам: за золото рецепты не продаются нигде (50.1). При 20 и ниже Торгрим не продаёт эпические предметы, а Брик берёт на 10% больше.

### 26.5 Баланс доходов и расходов (Акт 1, средний игрок)

- **Доход около 3400 монет:**

  - с врагов около 1200 (волки 180, охотники 375, корневые твари 300, элиты 360);

  - босс 400;

  - квесты 900 (3 сюжетных по 100, 5 побочных по 120);

  - продажа лута и материалов около 900.

- **Типичные расходы около 3000 монет:** зелья и склянки 400, кожаный набор и щит 600, фляга до 5 зарядов 800, оружие до +3 это 600, броня до +2 на двух частях 600.

- Остаётся около 400. Полное улучшение всего сразу невозможно, игроку приходится выбирать.

### 26.6 Защита от эксплойтов

- Все цены берутся только из Data Table, не из кода.

- Выполняется правило цены покупки и продажи (26.2), лимит монет у торговцев, выкуп без прибыли.

- Монеты не уходят в минус. Все покупки и продажи идут как атомарные транзакции (раздел 27.2).

- Вес и размер стека ограничены, лишнее нельзя подобрать.

## 27. Обмены и бартер

### 27.1 Бартер с NPC

- В окне торговли есть вкладка «Обмен»: вместо монет игрок отдаёт предметы. Курсы обмена лежат в Data Table и от репутации не зависят.

- **Примеры первой версии:**

  - 5 ржавого железа → 1 холодное железо (Торгрим);

  - 8 волчьих шкур → ремень «Стойкость», необычный, +20 к лимиту веса (Торгрим);

  - 3 клыка → амулет «Волчий зуб», необычный, +5% шанса крита (Брик);

  - 4 сухих корня → 1 противоядие (Мара);

  - 4 редких предмета → 1 эпический (Брик, не чаще раза в 10 отдыхов).

- **Правило без арбитража.** Сумма цен продажи отданных предметов должна быть не меньше цены продажи полученного. Иначе игрок обменяет дешёвое на ценное и перепродаст. Это проверяет автоматический тест при сборке Data Table.

### 27.2 Сервис обмена (готов к MMO)

- Единый интерфейс ITradeService. В первой версии реализация локальная (игрок и NPC), позже заменяется серверной.

- У каждого предмета есть GUID экземпляра и GUID типа. Золото целочисленное, округление вниз.

- **Транзакция атомарна** и проходит три шага: проверка, резервирование, фиксация. Проверяется владение, лимит веса, свободные слоты, достаточность золота, отсутствие привязки. При любой ошибке всё откатывается, ничего не теряется и не дублируется.

- У транзакции есть уникальный ID. Повторная отправка с тем же ID (двойной клик, повтор пакета) не выполняется второй раз.

- Квестовые и легендарные предметы привязаны к герою и не передаются.

- Журнал транзакций (ID, время, стороны, предметы, золото) хранится в сохранении, а в MMO в базе данных.

### 27.3 Обмен между игроками и аукцион (после первой версии)

- **Обмен:** оба игрока кладут предметы и золото в окно, любое изменение сбрасывает подтверждения и включает 5-секундную блокировку, затем оба подтверждают. Налог 5% с золота. Привязанное не передаётся.

- **Аукцион:** лоты с фиксированной ценой на 24 или 48 часов. Залог 2% при выставлении, комиссия 5% при продаже. Передача предмета и золота делается одной транзакцией базы данных с изоляцией SERIALIZABLE.

- **Защита:** лимит суммы обменов в сутки для новых аккаунтов, журнал для разбора споров, блокировка подозрительных паттернов (повторяющиеся обмены одной пары).

### 27.4 Тесты, которые должны проходить

1.  Обмен при нехватке места или веса: отказ, ничего не потеряно.

2.  Отключение посреди транзакции: полный откат.

3.  Двойной клик на «Подтвердить»: один результат.

4.  Покупка и немедленный выкуп: без прибыли и без убытка при выкупе.

5.  Золото не уходит в минус ни при каких действиях.

6.  Любой бартер из Data Table проходит правило без арбитража.

## 28. Крафт и улучшения

### 28.1 Станции

Наковальня у Торгрима (оружие и броня, огненное масло, перековка и разборка) и стол Мары (зелья, ядовитое и ледяное масла). Крафт без таймеров: мгновенно, с анимацией 2–3 секунды. Рецепты открываются только в мире: у NPC, из записок и книг, в наградах квестов, охот и боссов. За золото рецепты не продаются (раздел 50.1).

### 28.2 Рецепты первой версии

1.  **Зелье исцеления:** 2 травы + 1 склянка → лечит 30% здоровья за 8 секунд.

2.  **Зелье выносливости:** 2 травы + 1 сухой корень + склянка → +40% к регенерации выносливости на 60 секунд.

3.  **Противоядие:** 1 трава + 2 сухих корня + склянка → иммунитет к ядам спор на 90 секунд.

4.  **Настойка против спор** (рецепт с Матери Чащи, 15%): 2 травы + 1 клык + склянка → иммунитет на 180 секунд.

5.  **Холодное железо:** 5 ржавого железа → 1 слиток (на наковальне).

6.  Склянка покупается у Мары за 5 монет.

7.  Масла на оружие (огненное, ядовитое, ледяное): рецепты, материалы и где их учат, в разделе 47.2.

### 28.3 Улучшение оружия и брони

- **Оружие** до +5. На каждом шаге игрок выбирает ветку: урон +8%, скорость ударов +6% или устойчивость к оглушению +10, в одной ветке не больше трёх шагов (раздел 48.1). Цена: +1 это 100 монет и 1 ржавое железо, +2: 200 и 2, +3: 300 и 3, +4: 400, 4 железа и 1 холодное железо, +5: 500, 5 железа и Сердце Чащи.

- **Броня** до +3. Каждое +1 даёт +4 к броне. Цена: 100, 200, 300 монет и столько же единиц ржавого железа, сколько уровень улучшения.

- **Фляга пепла:** +1 заряд за 300 монет, второй за 500 монет. Максимум 5 зарядов в первой версии.

- **Источники железа:** около 4 штук с охотников, до 12 с элит, около 12 из залежей в шахте (8 узлов по 1–2 штуки), до 12 из разборки (не больше 2 за главу, 48.3). Хватает на одно оружие до +5 и одну-две части брони, на всё сразу не хватит (раздел 40).

### 28.4 Состав предметов первой версии (около 35)

- Оружие: стартовый меч, Клинок Корней, два торговых меча, двуручный меч, топор (6).

- Щиты: 2. Броня: 4 слота в 3 наборах (тряпичный, кожаный, кольчужный), 12.

- Расходники: 3 зелья, настойка, склянка, стрелы (6).

- Материалы: шкура, клык, ржавое железо, холодное железо, сухой корень, трава, Сердце Чащи, записки лора (8).

## 29. Прочие системы

- **Смерть.** Герой возрождается у последнего очага, обычные враги возрождаются. Потери по сложности (раздел 21.3). На «Пепельном» потерянное золото остаётся мешком на месте гибели и возвращается один раз; при следующей смерти до возврата мешок исчезает.

- **Очаги.** Отдых восстанавливает здоровье, фляги и ману, возрождает врагов, сохраняет игру, позволяет сменить сложность и показывает воспоминание (один раз на очаг). Каждый отдых увеличивает счётчик, по которому меняется ассортимент торговцев и растёт их запас золота.

- **Быстрое перемещение.** Между открытыми очагами из меню очага, бесплатно. Недоступно в бою и пока босс жив. Загрузка до 5 секунд за счёт стриминга World Partition.

- **Журнал и карта.** Журнал квестов (активные, завершённые, лор). Карта 1×1 км с отметками очагов, торговцев и заданий, открывается по мере исследования. Компас на экране.

- **Сохранения.** Автосохранение при отдыхе, смене зоны, после босса и каждые 5 минут вне боя. Несколько слотов, версия формата в каждом файле.

- **Подсказки.** Короткие подсказки управления в прологе (парирование, красные телеграфы). Отключаются в настройках. Под каждым активным квестом в журнале строка с ближайшим шагом, она отключается отдельно (раздел 50.2).

### 29.1 Достижения

В первой версии это внутренняя система, без привязки к магазинам. Награды только косметические (титулы и рамки в меню), на баланс боя и экономики они не влияют.

**Сюжет (6):**

- «Пепел»: пройти пролог.

- «Серая Топь»: дойти до деревни и поговорить с Марой.

- «Первая память»: увидеть воспоминание у очага.

- «Хранитель памяти»: увидеть все 6 воспоминаний Акта 1.

- «Письмо ворона»: получить письмо Эйлвина.

**Бой (10):**

- «Первая кровь»: убить первого врага.

- «Охотник»: выполнить все 6 именных охот (раздел 49).

- «Парирование»: 10 успешных парирований. «Мастер парирования»: 50.

- «Жар»: сжечь споровое облако огненным снарядом.

- «Без единого удара»: победить капитана охотников, не получив урона (скрытое).

- «Без фляг»: победить Мать Чащи, не используя фляги.

- «Пепельный»: пройти Акт 1 на сложности «Пепельный».

- «Горячий приём»: победить Мать Чащи с огненным маслом на оружии.

- «Сокрушитель»: оглушить шкалой элиту или мини-босса (раздел 46).

**Исследование (6):**

- «Первая тропа»: открыть все 6 очагов.

- «Шахтёр»: добыть 8 узлов ржавого железа.

- «Колокол»: вернуть колокол часовни.

**Экономика и развитие (7):**

- «Торговец»: продать предметов на 1000 монет.

- «Обмен»: совершить первый бартер.

- «Кузнец»: улучшить оружие до +3.

- «Алхимик»: сделать 10 зелий.

- «Опытный»: достичь 10 уровня.

**Выборы (3, скрытые):**

- «Правда о дани»: разоблачить Годрика.

- «Тихая сделка»: промолчать о дани.

- «Милосердие»: спасти дочь мельника.

**Как устроено:**

- Подсистема UAchievementSubsystem (GameInstance Subsystem). Игровые события (убийство, парирование, квест, сделка, очаг) приходят через Gameplay Tags и делегаты, подсистема не знает о конкретных классах.

- Таблица достижений в Data Table: ID, название, описание, тип условия, целевое число, скрытое ли, награда-титул, иконка.

- Прогресс (счётчики и даты) хранится в сохранении и версионируется вместе с ним.

- Интерфейс: окно в меню с прогрессом, всплывающее уведомление в углу при получении. Скрытые показываются как «???» до получения.

- Интерфейс IAchievementBackend: сейчас локальная реализация. При публикации в магазинах (Steam, Epic) подключаются их API, условия остаются прежними. В MMO условия считает сервер.

- Тесты: достижение выдаётся один раз, счётчики не сбрасываются при перезагрузке, достижения «без урона» и «без фляг» не засчитываются при провале условия.

## 30. Полная кампания: длина, регионы, выпуск

### 30.1 Длина

- Пролог около 15 минут, Акт 1 6–8 часов, Акт 2 9–11 часов, Акт 3 9–11 часов. Основная линия 25–30 часов, с побочными квестами 35–40.

- **Режим «Пепельный круг»** (новая игра плюс): ещё около 20 часов. Враги сильнее в 1,5 раза, открываются ранее закрытые ветки диалогов и предметы, меняются финальные сцены.

### 30.2 Регионы полной игры

1.  Серая Топь и Увядшая Чаща (Акт 1), уровни 1–10.

2.  Тарвен, речной торговый город (хаб 2), уровни 9–11.

3.  Скорбные Топи, уровни 10–14.

4.  Руины Каэр-Мора, уровни 13–17.

5.  Горы Молчания и Цитадель Стражей, уровни 16–21.

6.  Подгород Каэр-Мора, уровни 20–25.

7.  Склеп Бледного Двора, уровни 24–28. Предел уровня 30 достигается в «Пепельном круге».

Таблицу опыта врагов для актов 2 и 3 нужно пересчитать при проектировании: для уровня 28 суммарно нужно 56 700 опыта, и это не должно быть гриндом.

### 30.3 Как выпускаем

- **Этап A:** Акт 1 как играбельный вертикальный срез (первая версия, разделы 1–29).

- **Этап B:** Акт 2 (Тарвен, Скорбные Топи, Руины).

- **Этап C:** Акт 3 (Цитадель, Подгород, Склеп) и финалы.

- **Этап D:** «Пепельный круг» и подготовка онлайн-систем.

- Честная оценка: каждый акт по объёму сопоставим с первой версией или больше. Это месяцы работы на акт, а не недели. Нельзя строить всё сразу: следующий акт начинается только после того, как предыдущий проходится от начала до конца.

### 30.4 Что делает игру длинной, но не водянистой

- На каждом акте новая механика, палитра и тема: Акт 1 лес и выживание, Акт 2 болезнь и торговля, Акт 3 память и выбор.

- Нет заданий «принеси десять»: у каждого побочного квеста есть выбор, лор или последствие.

- Одни и те же персонажи возвращаются с изменёнными отношениями, поэтому ранние решения важны в финале.

### 30.5 Новые персонажи полной игры

- **Лиара Сталь:** последняя из Стражей-инспекторов, резкая, недоверчивая. Появляется в Тарвене. Её дуга: союзница против Эйлвина, судьба зависит от решения героя в Акте 2.

- **Брат Орен:** проповедник секты Милостивых, босс Акта 2. Его дуга: искренне верит, что несёт утешение.

- **Эхо Магистра Йорана:** последний настоящий Магистр, запретивший ритуал. Босс-испытание Акта 3.

- **Брик:** странствующий торговец, встречается во всех актах. Его маленькая дуга: он единственный, кто торгует с обеими сторонами, и это приведёт его к решению в финале.

## 31. Акты 2 и 3: подробный сюжет

### Акт 2 «Тарвен и руины»

**2.1 Дорога и Тарвен (уровни 9–11, около 3 часов).**

## 32. Диалоги: стиль, голоса, образцы сцен

Первый черновик ниже предложен ИИ. Чтобы права на тексты были надёжно ваши (раздел 33.1), финальные реплики главных сцен нужно переписать и отредактировать вручную.

### 32.1 Правила письма

- Каждая реплика делает одно из трёх: двигает действие, раскрывает характер или меняет отношения. Если не делает ничего, её нет.

- Лор не объясняется монологом. Он живёт в предметах, записках и реакциях людей.

- Подтекст важнее прямой речи: персонажи редко говорят то, что чувствуют.

- Реплики игрока короткие и бывают трёх тонов: сочувственный, практичный, жёсткий. Правильного ответа нет, у каждого своя цена.

- Запрещено: «избранный», «древнее зло пробудилось», пафосные клятвы, современный сленг и мемы, пересказ очевидного, фразы вроде «как ты знаешь».

- **Проверка:** закрой имя говорящего. Если реплику мог бы сказать другой персонаж, перепиши. Читай вслух: на слух ложь слышна лучше.

### 32.2 Голоса

- **Мара:** тихая, конкретная, говорит бытом (хлеб, печь, лунник), паузами. О магии абстрактно не говорит.

- **Торгрим:** короткие фразы, мерит всё железом, сухая ирония, не жалуется.

- **Годрик:** оправдывается; чем больше боится, тем длиннее фразы. Любимое слово: «пойми».

- **Эйлвин:** вежливый, мягкий, говорит как врач с больным. Предлагает выбор, которого нет.

- **Эльза:** шёпот, корни и травы как образы, обрывки колыбельной.

- **Гарет:** уставные формулы Ордена, коротко, сухо.

- **Исольд:** в прошедшем времени, путает залы и годы.

- **Лиара Сталь** (Акт 2): резкая, прямая, не доверяет красивым словам.

- **Брат Орен** (Акт 2): ласковый и страшный, зовёт всех «дитя».

## 35. Авторская тетрадь: что пишете вы

Цель: чтобы сюжет, имена, лор и диалоги стали вашими по-настоящему, а не только по виду. ИИ-текст в разделах 15, 16, 24, 31 и 32 считайте подсказкой, которую нужно заменить своим текстом. Перефразировать его недостаточно: правка слов не делает вас автором идеи и структуры.

### 35.1 Правила работы

1.  **Сначала вы, потом ИИ.** Пишете свой вариант, пусть грубый. Только после этого просите критику, а не новый текст.

2.  **ИИ не пишет финальные тексты.** Допустимо: вопросы к вам, поиск противоречий, проверка логики, замечания словами, проверка орфографии.

3.  **Не берите абзацы ИИ.** Берите из них только то, что вас зацепило как идея, и пишите заново: другая структура, свои образы и детали.

4.  **Ведите журнал авторства** (35.5): что придумали вы, что предложил ИИ, что отвергли, когда заменили.

5.  **Не скрывайте участие ИИ**, там где этого требуют магазины и правила. Скрытие обычно вредит больше, чем помогает.

6.  То же правило для кода: проверяйте и дорабатывайте то, что написал ИИ, и сохраняйте историю изменений с вашими правками.

### 35.2 Задания по сюжету (отвечайте своими словами)

- **Мир.** Что случилось с королевством? Опишите событие в 5–7 предложениях. Чего король хотел на самом деле, кого он любил?

- **Герой.** Кто он до потери памяти? О чём жалеет? Какой один поступок он бы не повторил?

- **Персонажи** (Мара, Торгрим, Годрик, Эйлвин, Исольд, Лиара, Орен, Гарет): для каждого ответьте на 4 вопроса. Чего хочет? Чего боится? Что скрывает? Какие три фразы сказал бы только он?

- **Поворот.** Какой поворот сюжета удивил бы вас самого? Сравните с поворотом из раздела 15.3 и оставьте только то, что вам действительно нравится.

## 36. Версия 2: длина, интерес, фарм

Разделы 36–43 добавлены после проверки двух вещей: хватит ли контента на долгую игру и не превращается ли прогресс в беготню по кругу. Короткий ответ: не хватало, и превращался. Ниже разобрано, что именно не сходилось и что мы с этим делаем. Все числа здесь стартовые, как и в разделах 21–29, их подтверждает плейтест. Эти разделы написаны ИИ как черновик и внесены в журнал авторства (35.5).

### 36.1 Что было не так

- **Длина не сходилась.** В разделе 14 Акт 1 проходится за 60–90 минут, а в разделе 30 он назван 6–8-часовым. Три типа врагов, один босс, карта 1×1 км и восемь квестов дадут 2–3 часа, а не 6–8. Срез на 60–90 минут нормален как технический этап, но это не готовая игра.

- **Враги быстро надоели бы.** Три обычных врага на семь часов. К третьему часу игрок видел бы всё, что они умеют.

- **Фарм был встроен в правила.** Обычные враги возвращались при каждом отдыхе, а в разделе 22.4 даже названы четыре «точки фарма». Игре самой было выгодно, чтобы игрок ходил по кругу.

- **Награду давали в основном убийства.** Опыт, золото и материалы шли с врагов. Квесты и исследование мира платили скромнее, чем пробежка по одной тропе.

- **Не было ритма.** Раздел 15 рассказывал сюжет, но нигде не было написано, что игрок делает каждые десять минут и почему ему захочется продолжить.

### 36.2 Что решаем

- Акт 1 становится прологом и шестью главами. Основная линия около 5,5 часа, со всем остальным до 8 часов (раздел 37).

- Игру удлиняем содержанием: места, враги, решения, тайны. Повторением не удлиняем (разделы 38 и 39).

- Награда идёт за исследование и решения. Повторное убийство не окупается (разделы 40 и 41).

- Побочных квестов не пять, а двенадцать. В каждом выбор, место или история (раздел 42).

- Срез из раздела 14 остаётся как этап A0. Полный Акт 1 это этап A (раздел 43).

### 36.3 Что поправлено в старых разделах

Чтобы документ не спорил сам с собой, в старых разделах исправлены места, которые противоречили новым: 2 (правило 8), 14, 15.8, 20 (очаги), 22.4, 28.3, 29.1 (достижения), 30.2, 34, 35.5. Экономика (26.5) пересчитывается в 41.3. Если остались расхождения, главнее разделы 36–43.

## 37. Акт 1 целиком: пролог и шесть глав

Карта вырастает с 1×1 до примерно 1,5×1,5 км, и к ней добавляются три подземных уровня: подвал мельницы, шахта и логово. Длинной игру делает не размер, а плотность: петли с короткими путями назад, высоты, двери, которые открываются позже, места, куда хочется вернуться. Очагов теперь шесть: сожжённая часовня, Серая Топь, мельница, охотничий лагерь, шахта и врата логова.

### 37.2 Пролог «Угли» (15 минут)

- **Что делаем.** Просыпаемся в сожжённой часовне, выбираем имя и внешность, учимся двигаться, уклоняться, бить и блокировать. Первый бой с волками на дороге.

- **Новое.** Дар «Огненный снаряд» и первое воспоминание у очага часовни.

- **Нарочное поражение.** На выходе на дорогу героя встречает Сборщик Двора, бледный рыцарь с цепью и серпом, и убивает одним ударом. У него нет полоски здоровья, и игра этим говорит: этот бой не выиграть. Герой просыпается у очага. За две минуты игрок узнаёт, как работает смерть, и запоминает врага, с которым встретится в главе 5.

- **Конец главы.** Дорога в Серую Топь, на горизонте дым.

### 37.3 Глава 1 «Осада» (Серая Топь)

- **Что делаем.** Пробиваемся в осаждённую деревню, знакомимся с Марой, Торгримом и старостой Годриком, осваиваем торговлю, крафт и улучшения. Первая ночь: оборона деревни, три волны примерно на 8 минут. Это один раз и без повторов.

- **Новое.** Хаб с торговцами, лазарет Мары, наковальня Торгрима. Дар «Исцеление» у деревенского очага. Заражённые селяне: враги, которых жалко бить (раздел 39).

- **Бои.** Селяне и волки. Финал главы: мини-босс Серый Клык, вожак стаи, бывший пёс Годрика.

- **Очаг.** Серая Топь. Воспоминание: человек в плаще Стража ночью у деревенского колодца. Герой здесь уже был.

- **Конец главы.** После боя герой видит, как Годрик отдаёт мешок фигуре в бледном плаще. Плащ знаком по прологу. За что платит староста и кому?

### 37.4 Глава 2 «Тропа и мельница»

- **Что делаем.** По Волчьей тропе идём к мельнице. Первое открытое пространство: три маршрута, первые тайники. На мельнице подвал-подземелье и загадка со шлюзом: пока вода не спущена, проход закрыт.

- **Новое.** Брик, странствующий торговец, и его карта. Первый ярлык (мельница ведёт назад в деревню). Первая загадка с механизмом.

- **Бои.** Волки, ловчие с капканами (учат смотреть под ноги), споровики (учат бить издалека), душители в ветвях (учат смотреть вверх).

- **Очаг.** Мельница. Воспоминание: дорога под дождём и рука на карте. Герой получает «Память дороги».

- **Конец главы.** За мельницей начинается Чаща. У воды цветёт лунник, хотя здесь давно ничего не цветёт.

### 37.5 Глава 3 «Охотничий лагерь»

- **Что делаем.** Лагерь захвачен одержимыми, часть охотников ещё держится на вышках. Возвращаем лагерь, решаем, кому верить, ищем след Двора.

- **Новое.** Дар «Ледяной щит». Щитоносцы и лучники на вышках: бой становится вертикальным. Первое расследование («Чужие следы»).

- **Бои.** Лагерь как большая арена с палатками и вышками. Элита: капитан охотников (22.3).

- **Очаг.** Охотничий лагерь. Воспоминание: учитель вручает нож-ключ и говорит, что он сработает один раз (намёк из раздела 20, пункт 6).

- **Конец главы.** В записках лагеря сказано, что охотников когда-то нанял Годрик, чтобы держать Чащу закрытой. Ключ капитана у героя, но замков два: второй в шахте.

### 37.6 Глава 4 «Шахта»

- **Что делаем.** Настоящее подземелье на три уровня вглубь: ловушки, подъёмники, тупики, короткие пути назад к очагу. Идём за вторым ключом и железом для Торгрима.

- **Новое.** Тёмные участки и факелы. Подъёмники, которые открываются с обратной стороны. «Память глубины» после воспоминания.

- **Бои.** Корневые твари, щитоносцы и ловчие в тесных коридорах. Те же враги, что в лагере, но в тесноте это другой бой. Элита: корневой страж.

- **Передышка.** Обвал. Три минуты бега от рушащегося тоннеля без боя. Нужна, чтобы сбить ритм после долгой череды схваток.

- **Очаг.** Шахта, самый глубокий уровень. Воспоминание: падение в темноту и тихая колыбельная откуда-то снизу.

- **Конец главы.** Тайный проход в конце шахты выводит в Чащу, к дому у лунника.

### 37.7 Глава 5 «Сердце Чащи»

- **Что делаем.** Идём через туман к логову. Дороги почти нет, ориентируемся по деревьям, тропам и звуку. Необязательно заходим в дом Эльзы за цепочкой из лунника.

- **Новое.** Туман как механика: без колокола видно метров на пятнадцать, с колоколом (квест «Колокол часовни») метров на сорок. Меньше врагов, больше тревоги.

- **Бои.** Несколько корневых тварей и два душителя. На подходе к логову мини-босс: Сборщик Двора, тот, что убил героя в прологе. Реванш.

- **Очаг.** Врата логова. Воспоминание: герой стоит здесь же с ножом, учитель зовёт его «ученик», а имя заглушает шум.

- **Конец главы.** Умирая, Сборщик говорит: «Она ждёт. Давно».

### 37.8 Глава 6 «Мать Чащи и возвращение»

- **Что делаем.** Босс по разделу 23.2. С цепочкой из лунника бой можно закончить мирно. Потом возвращение в деревню.

- **Возвращение.** Деревня выглядит так, как её изменили решения игрока (38.5). Мара напевает мелодию, которую герой слышал в шахте. Разговор с Годриком о дани. Здесь же сдаются многие побочные квесты.

- **Конец главы.** Прилетает ворон с письмом Эйлвина. В письме есть деталь, которую мог знать только тот, кто был в Чаще. Дорога на Тарвен открыта.

## 38. Что держит игрока: темп, вопросы, решения

### 38.1 Три петли

- **Короткая (5–10 минут).** Выбрал цель, дошёл, встретил что-то новое, получил награду: находку, ярлык, очаг, реплику, вид.

- **Средняя (глава, 50–100 минут).** Вопрос, дорога, первая часть ответа, новый вопрос. Глава заканчивается так, чтобы хотелось открыть следующую.

- **Длинная (акт и игра).** Кто герой, что скрывает учитель, чего стоит Уголь. Каждое воспоминание сдвигает картину, но не закрывает её.

### 38.2 Правило десяти минут

- Больше десяти минут подряд без события быть не должно. События: новый тип врага, находка, развилка, диалог, панорама, загадка, воспоминание, ярлык.

- От очага до следующего очага или ярлыка не больше 8–10 минут пути.

- Не больше двух боёв подряд с одним и тем же набором врагов.

- После тяжёлого боя (элита, мини-босс) идёт тихий участок: ходьба, разговор, находка.

### 38.5 Решения с видимыми последствиями

- **Серый Клык.** Убить или вернуть Исцелением. Вернувшийся пёс остаётся у ворот деревни.

- **Что защищать ночью.** Ворота, амбар или лазарет. Что не защитили, того нет: пустые ворота, дорогие зелья, раненые, которых не спасли.

- **Чужие следы.** Кого обвинить в лагере. Ошибка стоит доверия капитана.

- **Беглец из шахты.** Донести, отпустить или убить.

- **Дань старосты.** Разоблачить или промолчать (15.6).

- **Мать Чащи.** Бой или цепочка из лунника (23.2).

- **Как это видно.** В главе 6 деревня показывает последствия картиной, а не меню: кто стоит на воротах, открыты ли лавки, где староста, жив ли пёс, кто остался на мельнице. Из шести решений минимум четыре видны на улицах.

### 38.6 Чего избегаем

- Пустых переходов без событий и без вида на что-то новое.

- Длинных диалогов без выбора. Если разговор длиннее минуты, в нём должна быть развилка или важный факт.

- Обязательной прокачки перед боссом. Босс проходится умением, уровень даёт запас, но не заменяет его (39.4).

- Заданий «принеси N» и «убей N».

### 39.3 Модификаторы

Чтобы знакомые враги не наскучили, у некоторых есть метка. Ставит её дизайнер вручную, случайных меток нет, в одной группе не больше одной. Исключение: именная цель охоты может нести две метки (49.1).

- **Спороносный.** После смерти оставляет облако спор.

- **Яростный.** Быстрее на 15% и больнее на 15%, это видно по красным глазам.

- **Закалённый.** Здоровья на 30% больше и запас оглушения на 30% больше (46.1), видны корни на броне.

- **Тихий.** Не шумит и нападает из засады, выдаёт себя только звуком.

### 39.4 Как строим бои

- Вокруг героя одновременно не больше трёх врагов, в тесных местах двое.

- В группе разные роли: тот, кто бьёт вплотную, тот, кто стреляет, и тот, кто мешает (ловчий, споровик).

- Новый тип сначала встречается один, потом в компании других.

- Место участвует в бою: высоты, колонны, узкие проходы, вода.

- Бой читается: телеграфы по разделу 23.1 у всех врагов.

- Уровень героя помогает, но не решает. Превышение уровня врага на три и больше упрощает бой не больше чем на 20%. Игрок выигрывает навыком, а не часами в одной точке.

### 39.5 Три стиля оружия

Каждый стиль это отдельный ритм боя с собственными ударами, а не просто другая модель. Меняется оружие вне боя, у очага. Это ещё одна причина пройти игру второй раз.

- **Меч и щит.** Быстро и безопасно, лучше всего для парирования. Особый приём: «Ответный выпад» сразу после парирования.

- **Двуручный меч.** Медленно, широко, оглушает. Особый приём: «Сокрушение», заряженный удар, ломающий щиты.

- **Топор.** Средний темп и серия из четырёх ударов. На третьем ударе снижает броню цели на 10 на пять секунд.

## 40. Против фарма

Цель простая: прогресс должен идти от приключения, а не от повторов. Игрок может выбрать фарм сам, но игра его к этому не подталкивает и не платит за него хорошо. Если эти правила спорят с разделом 22, главнее этот раздел.

### 40.1 Правила

- **Возрождение ограничено.** Обычный враг возвращается после отдыха у очага не больше двух раз, потом исчезает навсегда. Элиты, мини-боссы, боссы и сюжетные враги не возвращаются совсем.

- **Повтор не платит.** Опыт с возрождённого врага ×0,5 в первый раз и ×0,25 во второй. Если одновременно действует штраф за уровень из 22.4, берётся меньший множитель, они не перемножаются. Золото ×0,5 и ×0. Материалы с возрождённых врагов не падают.

- **Редкое не падает с обычных врагов.** Из таблиц волков, охотников и корневых тварей (22.3) убираем шансы на необычные и редкие предметы. Остаются шкуры, корни, стрелы, расходники и золото. Необычные и выше лежат в тайниках, у мини-боссов и в наградах квестов.

- **Ничего важного не зависит от удачи.** Рецепт настойки против спор раньше падал с босса с шансом 15% (22.5), теперь он гарантированная награда квеста «Рецепт Эльзы». Удача даёт только приятные дополнения, но не вещи, без которых билд не собрать.

- **Материалы конечны.** Железо, сухие корни, смола, иней и Сердце Чащи лежат в мире и не возрождаются. Железа в Акте 1 около 30 единиц и до 12 из разборки с лимитом 2 за главу (48.3): на оружие до +5 уходит около 20 (с холодным железом), на одну броню до +3 около 6. Всё сразу не улучшить, игрок выбирает, что усиливать. Трава для зелий и масел растёт на мельнице и обновляется раз за главу, а не за отдых.

- **Награда за новое.** Первое убийство каждого вида даёт утроенный опыт. Каждому мини-боссу +30 опыта за первую победу. В бестиарии появляется запись со значками уязвимостей (45.4), а после того как игрок парировал все атаки вида, ещё и знание врага: +10% урона по этому виду. Знание врага работает вместе с уязвимостями, множители перемножаются.

- **Опыт идёт из мира.** Квесты, находки, воспоминания и бестиарий дают около 45% всего опыта Акта 1 (раздел 41). Новая зона, тайник, записка, очаг дают опыт один раз.

- **Деньги идут из заданий.** С обычных врагов золота меньше, чем в 26.5 (около 1 000 вместо 1 200). Разница возвращается через квесты, тайники и продажу находок (41.3).

- **Нет заданий «убей N» и «собери N».** В каждом квесте выбор, история или новое место (30.4).

- **Нет ежедневных и таймерных наград.** Игра не просит возвращаться «каждый день».

- **Дорога назад короче.** У каждой зоны есть ярлык к своему очагу, между открытыми очагами работает быстрое перемещение (29). Квест не должен заставлять идти одним и тем же путём больше двух раз.

### 40.2 Как проверить, что фарма нет

- **Тест «30 минут на месте».** Игрок полчаса возрождает врагов в самой выгодной точке. Он должен получить не больше 40% опыта, который за те же полчаса дало бы обычное прохождение.

- **Доля повторов.** Повторяющиеся бои (после респауна и в тех же местах) занимают в игровом времени не больше 15%.

- **Минимальное прохождение.** Игрок проходит только основную линию, без побочных. К Матери Чащи он приходит на уровне 7, босс проходится без фарма.

- **Обратный тест.** Игрок, который «перекачался» на два уровня, не должен проходить босса без усилий (39.4).

## 45. Статусы и уязвимости врагов

Сейчас у врагов нет ничего, кроме здоровья и брони, и у героя нет причин выбирать огонь или клинок. Статусы и уязвимости дают причину: игрок смотрит на врага и решает, чем его бить. Урон статусов небольшой, ценность в выборе и в том, что он не зависит от брони.

### 45.1 Пять статусов

| **Статус**   | **Чем наносится**                              | **Что делает**                                                                               | **Длительность** |
|--------------|------------------------------------------------|----------------------------------------------------------------------------------------------|------------------|
| Горение      | Огненное масло, Огненный снаряд, горящие бочки | 6 урона в секунду. Звери (волки) в панике бегут от героя 3 с. Сжигает споровые облака (23.2) | 5 с              |
| Яд           | Ядовитое масло                                 | 4 урона в секунду. Цель бьёт на 10% слабее                                                   | 10 с             |
| Кровотечение | Меч и топор                                    | 4 урона в секунду                                                                            | 6 с              |
| Увядание     | Клинок Корней (шанс 10%, 22.5)                 | 3 урона в секунду. Шкала оглушения цели не убывает                                           | 8 с              |
| Стужа        | Ледяное масло                                  | Движение и атаки медленнее на 25%. Шкала оглушения набирается на 25% быстрее                 | 5 с              |

### 45.2 Как копится статус

- **Шкала заряда.** У каждой цели для каждого статуса своя шкала. Порог по умолчанию 100. Если 3 секунды не было попаданий, шкала убывает на 8 в секунду.

- **Источники заряда.** Масло: 25 за каждое попадание. Огненный снаряд: 60 Горения. Одноручный меч (стартовый, торговые, Клинок Корней): 10 Кровотечения за удар, топор: 20, двуручный меч: 0 (его сила в оглушении, раздел 46).

- **Наложение.** Когда шкала достигла порога, статус накладывается, а шкала обнуляется. Следующие 6 секунд цель невосприимчива к тому же статусу, поэтому держать врага в нём вечно нельзя.

- **Повтор.** Новое наложение во время действия только обновляет длительность, урон не растёт.

- **Урон.** Урон статусов игнорирует броню и не бывает критическим.

- **Огонь и стужа** отменяют друг друга: новый статус снимает старый.

- **Увядание** накладывается сразу с шансом 10% (22.5), шкала не нужна. Врагам с иммунитетом к увяданию оно не вредит.

- **Мир участвует.** Масляные бочки в лагере и шахте (23.3) загораются от Горения и Огненного снаряда: взрыв 40 урона по области 3 м, задевает и героя.

- **На героя** в Акте 1 действуют только яд спор (23.2) и капкан ловчего (39.1). Горение и кровотечение героя появятся вместе с новыми врагами Акта 2.

### 45.3 Уязвимости врагов

**У** уязвим: порог статуса 60 вместо 100, стихийный урон ×1,5. **С** сопротивляется: порог 200, стихийный урон ×0,5. **И** иммунитет: статус не накладывается, стихийный урон масла 0. Прочерк: обычно. Стихии это огонь, яд и стужа. Кровотечение и увядание не стихии и меняют только порог.

| **Враг**           | **Огонь** | **Яд** | **Кровь** | **Увяд.** | **Стужа** | **Почему**                           |
|--------------------|-----------|--------|-----------|-----------|-----------|--------------------------------------|
| Заражённый селянин | –         | У      | У         | –         | –         | Живой, без доспехов                  |
| Увядший волк       | У         | С      | У         | –         | –         | Зверь боится огня, яд уже в крови    |
| Споровик           | У         | И      | И         | С         | –         | Горящий споровик взрывается на месте |
| Охотник-мечник     | –         | –      | У         | –         | –         | Обычный бой, без особенностей        |
| Охотник-лучник     | –         | –      | –         | –         | У         | Замёрзший стрелок целится дольше     |
| Ловчий             | У         | –      | –         | –         | –         | Верёвки и шкуры горят                |
| Щитоносец          | –         | У      | С         | –         | –         | Броня гасит порезы, яд идёт в щели   |
| Ветвяной душитель  | У         | И      | С         | И         | –         | Горящая ветвь срывает захват         |
| Корневая тварь     | У         | И      | С         | И         | С         | Дерево горит, соки не отравить       |

**Элиты, мини-боссы и боссы:**

- Серый Клык как волк. Капитан охотников без уязвимостей. Корневой страж как корневая тварь.

- Сборщик Двора: У огонь (Двор боится Угля), С стужа, И увядание.

- Хранитель Старого Дуба: И огонь (священное дерево), У стужа, И яд, И кровотечение, И увядание.

- Мать Чащи: стихийный урон по числам из 23.2 (огонь ×1,5, стужа ×0,8) вместо общих множителей. Порог Горения как у уязвимых (60), стужи как у сопротивляющихся (200), кровотечение сопротивляется, яд и увядание не действуют. Множитель босса ×3 к порогу применяется сверху.

- Порог статуса у элит и мини-боссов ×2, у боссов ×3, длительность у боссов вдвое короче. Паника и замедление стужей на элитах и боссах не действуют, на боссе стужа даёт только ускоренный набор оглушения.

### 45.4 Как игрок узнаёт уязвимости

- **Бестиарий.** Запись открывается после первого убийства вида (40.1), значки уязвимостей сразу в ней. У элит и боссов значки открываются после первого боя.

- **Вид врага.** Подсказки в самом образе: споровик светится зелёным, у корневой твари видны сухие трещины, у щитоносца блестит металл. Это задача арта, она заносится в таблицу ассетов.

- **Слова NPC.** По одной реплике: Мара про споры и корни, Торгрим про щиты, Брик про волков. Про Мать Чащи герой узнаёт заранее из записки Эльзы: корни боятся огня.

- **Знание врага.** «Слабость» из 40.1 (+10% урона, когда игрок парировал все атаки вида) теперь называется «знанием врага». Она работает вместе с уязвимостями, множители перемножаются.

### 45.5 Что должно получиться

- **Выигрыш от подготовки.** Правильный выбор (масло, дар или стиль оружия) ускоряет бой с врагом от 100 здоровья на 25–40%, с мини-боссом на 20–30%, с Матерью Чащи на 15–25%. У слабых врагов (до 70 здоровья) выигрыш по времени мал, зато меняется ход боя: волки в панике, горящий споровик взрывается там, где стоит.

- **Нет наказания.** Неправильное масло не делает бой дольше, чем без масла: оно просто не помогает.

- **У каждого статуса есть цель.** Горение против зверей и растений, кровотечение против людей без щитов, яд против щитоносцев и селян, стужа против лучников и Хранителя.

- **Автотест Data Table.** У обычного врага от одной до трёх уязвимостей, и нет врага, уязвимого ко всем статусам сразу.

- **Данные и код.** Таблица EnemyAffinity (враг, статус, уровень: У, С, И), StatusEffectComponent на врагах копит заряды и накладывает GameplayEffect, расчёт на сервере (раздел 10).

Огненный снаряд даёт 10 любому стилю. Стужа (45.1) ускоряет набор на 25%. Остальные удары серии топора считаются лёгкими.

### 46.3 Что происходит, когда шкала заполнена

- **Оглушение.** Атака врага прервана (красные зоны, которые уже выпущены, остаются), враг стоит без действий в течение времени из 46.1.

- **Добивание.** Оглушённого обычного врага или элиту можно добить с множителем 2,0 (после парирования остаётся 3,0 из 21.2). На боссе вместо добивания урон ×1,25 на время оглушения.

- **После оглушения** шкала обнуляется, и повторное оглушение невозможно: 8 секунд у обычных врагов, 15 у элит и мини-боссов, 20 у боссов.

- **Убывание.** Если 4 секунды не было попаданий, шкала убывает на 10 в секунду (у боссов на 5). Увядание останавливает убывание.

- **Парирование** из 21.2 работает как прежде: оглушает на 1,5 секунды, открывает добивание ×3,0 и вдобавок заполняет шкалу. Если шкала при этом заполнилась, берётся более долгое оглушение, они не складываются.

- **Щитоносец.** Тяжёлый удар и парирование по-прежнему ломают его щит (39.1). Это отдельный эффект: оглушение даёт только заполненная шкала.

- **Оглушения из 23.2** (рывок Матери Чащи в колонну на 4 секунды, переход между фазами) от шкалы не зависят.

### 46.4 Устойчивость героя к оглушению

- **Сила атаки врага** зависит от замаха (23.1): быстрая 10, средняя 20, тяжёлая и красные зоны 40.

- **Устойчивость героя.** По умолчанию 0: любой удар прерывает действие героя, как сейчас (раздел 8). Если сила удара не выше устойчивости, герой продолжает атаку и не отшатывается, но урон получает полностью. 10 устойчивости защищает от быстрых ударов, 20 ещё и от средних. Тяжёлые удары и красные зоны (40) пробивают любую устойчивость, потолок которой 30.

- **Откуда берётся.** Ветка «Устойчивость» у оружия (48.1), по 10 за шаг, и щит «Железный лоб» из охоты (49.2), +10. Из всех источников вместе не больше 30.

- **Блок.** Удар, поглощённый блоком, героя не прерывает. Оглушает только пробитый щит (21.2).

### 46.5 Чем теперь отличаются стили оружия

- **Меч и щит.** Оглушает через парирование: 50 за успешное, после него «Ответный выпад» ещё 25. Капитана охотников (100) оглушают два парирования.

- **Двуручный меч.** Оглушает сам и не требует парирования: «Сокрушение» 60 плюс один тяжёлый удар 30 оглушают корневую тварь (90). Зато тяжёлый удар стоит 28 выносливости, и промах наказывает.

- **Топор.** Ровный набор: серия из четырёх ударов даёт 27, то есть оглушает селянина, волка и споровика за одну серию, а третьим ударом ещё и снимает броню (39.5).

### 46.6 Что проверяем

- Обычный враг оглушается 1–2 раза за бой при игре в любом из трёх стилей, босс 2–4 раза за весь бой.

- Ни один враг не оглушается чаще, чем раз в 8 секунд (невосприимчивость из 46.3).

- Устойчивость героя из всех источников не больше 30 (автотест при сборке Data Table).

- Данные: запас и время оглушения в таблице врагов, у врагов StaggerComponent, расчёт на сервере. Ни одного числа в коде.

## 47. Масла на оружие

Масло это временное покрытие оружия: огонь, яд или лёд. Игрок готовится к конкретному бою, а не просто копит ресурсы. Масла делаются из материалов мира, их нельзя купить, и они не заменяют оружие, а меняют то, как оно работает против нужного врага.

### 47.1 Как работает

- **Одно масло за раз.** Новое заменяет старое. Масло держится 8 минут игрового времени («Путник» 10, «Пепельный» 6). Его снимает только отдых у очага и конец таймера. Смерть масло не снимает, иначе каждая неудачная попытка на боссе сжигала бы запас, а смол на весь Акт 1 хватает только на 7 огненных масел.

- **Нанесение.** Из быстрого меню, 1,5 секунды, только вне боя (пока враги не заметили героя). У ворот Матери Чащи это значит: отдохнуть, нанести масло, войти.

- **Что даёт.** Дополнительный урон стихией 12% от базового урона из 21.2 (урон оружия + 0,5 × Сила или Ловкость), он игнорирует броню, и 25 заряда статуса за каждое попадание (45.2). Уязвимости из 45.3 умножают бонус.

- **Вид.** Оружие светится: огонь оранжевым, яд зелёным, лёд бело-голубым. Для этого используется общий материал свечения оружия (23.1).

- **Дары Угля** с маслом не связаны: Огненный снаряд работает так же, как без масла.

### 47.2 Рецепты и материалы

| **Масло** | **Из чего**                            | **Где учат**                      | **Запасной путь**                                  | **Станция** |
|-----------|----------------------------------------|-----------------------------------|----------------------------------------------------|-------------|
| Огненное  | 2 смолы + склянка                      | Торгрим, глава 1, после осады     | Мара в главе 2, если разговор с Торгримом пропущен | Наковальня  |
| Ядовитое  | 1 споровый мешочек + 1 трава + склянка | Записка ловчего в лагере, глава 3 | Мара в начале главы 5, если записка не найдена     | Стол Мары   |
| Ледяное   | 1 иней + 1 трава + склянка             | Записка штейгера в шахте, глава 4 | Торгрим после квеста «Холодное железо»             | Стол Мары   |

- **Смола.** Смоляные наросты на корнях и стволах, 14 штук на весь Акт 1: по 3 в главах 1–2, по 2 в главах 3–5 и 2 как награда охоты «Старая Плеть». Хватает на 7 огненных масел.

- **Споровый мешочек.** Падает со споровика при первом убийстве с шансом 40% (около 5 штук) и ещё 3 даёт охота «Хозяин омута». Хватает примерно на 8 ядовитых масел.

- **Иней.** Налёт на стенах шахты, 6 залежей по 1 штуке (глава 4). Хватает на 6 ледяных масел.

- Все три материала не возрождаются и не падают с возрождённых врагов (40.1). Цены в 26.1, торговцы их не продают.

- **Запасной путь** открывается только тогда, когда основной уже пропущен, иначе он стал бы основным: доверие деревни стартует с 50 (24.2), поэтому условие «доверие от 40» выполнялось бы с первой минуты.

- **Масла не продаются, не покупаются и не обмениваются**, поэтому из них нельзя сделать валюту. Склянка за 5 монет и трава это вся цена в монетах.

- **Всего** около 21 масла за Акт 1, то есть около трёх часов действия за 7–8 часов игры. Этого хватает на все бои с элитами и мини-боссами (5), на Мать Чащи, на Хранителя и на несколько трудных групп.

### 47.3 Баланс и правила

- Правильное масло ускоряет бой так, как сказано в 45.5. Мать Чащи без масла 4–6 минут, с огненным 3–4,5 минуты (+25% урона из-за огня ×1,5).

- Масло находится на оружии в руках. Смена оружия у очага (39.5) всё равно снимает его вместе с отдыхом.

- Оставшееся время хранится в сохранении. В паузе, в меню и во время сцен таймер стоит.

- Данные: Data Table масел (стихия, 12%, заряд 25, длительность), на оружии GameplayEffect с длительностью.

- Тесты: масло нельзя продать, купить и обменять, таймер переживает сохранение и загрузку, отдых снимает масло, смерть не снимает, новое масло заменяет старое.

## 48. Улучшения: ветки, перековка, разборка

### 48.1 Ветки улучшения оружия

Раньше каждое +1 давало всем одинаковые +8% урона (28.3). Теперь на каждом шаге игрок выбирает ветку. Из одного и того же железа два игрока получат разные мечи.

| **Ветка**    | **За один шаг**                                                           | **Кому подходит**                 |
|--------------|---------------------------------------------------------------------------|-----------------------------------|
| Урон         | +8% урона оружия                                                          | Тем, кто хочет убивать быстрее    |
| Скорость     | +6% скорости ударов (замахи и серии), расход выносливости за удар прежний | Лёгким сериям и топору            |
| Устойчивость | +10 устойчивости к оглушению (46.4), пока оружие в руках                  | Двуручному мечу и боям с группами |

- **Шаги и цены** прежние (28.3): пять шагов, 100–500 монет, железо 1–5, на +4 холодное железо, на +5 Сердце Чащи.

- **Выбор.** На каждом шаге одна из трёх веток. В одной ветке не больше трёх шагов, поэтому «всё в урон» собрать нельзя.

- **Числа сходятся со старыми.** Раньше +5 давали +40% урона. Теперь лучшая по темпу сборка «3 урона и 2 скорости» даёт 1,24 × 1,12, то есть около +39% к темпу урона. Сборка «3 урона и 2 устойчивости» даёт +24% и устойчивость 20.

- **Смена выбора.** У Торгрима: 50 монет × номер шага, материалы не тратятся, меняется один шаг за раз.

- **Броня остаётся линейной** (+4 брони за шаг, 28.3). Ветки только у оружия, иначе работы вдвое больше. Решение пересматриваем после плейтеста (52.4).

- **Уникальное оружие** (Клинок Корней, Обет Железа) улучшается по тем же веткам, его особое свойство не меняется.

- Данные: WeaponUpgradeTable (шаг, ветка, GameplayEffect). Выбор хранится в экземпляре предмета (по GUID) и версионируется в сохранении.

### 48.2 Свойства предметов и перековка

- **Узкий коридор.** Случайные свойства из 22.2 берутся из пула типа предмета. Значение равно базовому, умноженному на множитель редкости (22.2), разброс броска ±10%.

- **Без перезагрузок.** Свойства предметов в тайниках и наградах бросаются один раз при создании мира от зерна сохранения. Перезагрузка их не меняет, поэтому сохраняться перед сундуком бессмысленно.

- **Пул оружия** (базовые значения при ×1,0): «Острота» +3 урона, «Быстрота» +4% скорости ударов, «Меткость» +2% шанса крита, «Искра» +1 мана за удар, «Напор» +8% к набору оглушения.

- **Пул брони:** «Крепость» +3 брони, «Бодрость» +5 к запасу сил, «Живучесть» +6 здоровья, «Спороустойчивость» −10% урона ядом спор, «Лёгкость» +6% к регенерации выносливости.

- **Перековка.** У Торгрима, один раз на предмет. Торгрим показывает все свойства пула, которых ещё нет на предмете, игрок выбирает одно, и оно заменяет одно из случайных свойств предмета (на выбор игрока). Новое свойство получает среднее значение без разброса. Случайности нет, поэтому перезагрузка ничего не даёт.

- **Цена** 0,5 от базовой стоимости предмета (26.1): необычный 30 монет, редкий 100, эпический 350.

- **Что нельзя перековать:** предметы без случайных свойств, уникальные свойства легендарных, сюжетные предметы и уже перекованные (флаг в экземпляре).

- **Без эксплойтов.** Перековка не меняет цену продажи (0,30 от базовой по 26.2), выкуп (26.2) возвращает предмет вместе с флагом, платят только монетами.

### 48.3 Разборка предметов

- **Где.** Наковальня Торгрима, бесплатно.

- **Что можно разобрать.** Необычное и редкое оружие и броню, найденные в мире или полученные в награду (флаг «найдено»). Нельзя: обычные (их продают), эпические, легендарные, уникальные, сюжетные, купленные и полученные бартером.

- **Результат** только из материалов, которые уже есть в игре. Металл (оружие, кольчуга): 1 ржавое железо у необычного, 2 у редкого. Кожа и ткань: 2 шкуры у необычного, 2 шкуры и 1 сухой корень у редкого.

- **Лимит.** Железа из разборки не больше 2 за главу и около 12 за весь Акт 1 (счётчик в сохранении). Достигнув лимита, Торгрим говорит, что больше металла не выйдет до следующей главы. Остальные материалы без лимита.

- **Зачем лимит.** Железо конечно по замыслу (40.1). Без лимита разборка стала бы новым фармом: нашёл, разобрал, улучшил. Флаг «найдено» закрывает путь «купил, разобрал»: железо купить нельзя.

- **Итог по железу.** В Акте 1 около 30 в мире и до 12 из разборки, то есть 42. Одно оружие до +5 (около 20 с холодным железом), второе до +4 (около 15) и две части брони до +3 (12) стоят около 47, так что всё сразу по-прежнему не улучшить. До +5 можно довести только одно оружие: Сердце Чащи в Акте 1 одно.

## 49. Именные охоты

### 49.1 Что это

Охота это разовый заказ на доске заданий на конкретного врага: у него есть имя, история и награда. Это не квесты из раздела 42 (у них нет моральных выборов) и не «убей N»: в каждой охоте есть след, который нужно найти, и бой с особенностью. Охоты дают «ещё немного поиграть» без гринда и заменяют бессмысленное убийство волков по кругу.

- **Две доски:** в Серой Топи и в охотничьем лагере (глава 3). Шесть охот в Акте 1, по одной на главу. Охота появляется на досках, когда игрок впервые входит в зону её главы. Главы 3 и 4 идут в любом порядке (37.1), поэтому доска Серой Топи показывает все открытые заказы, а доска лагеря те же заказы, что и Серая Топь.

- **Отдельный раздел журнала** «Охоты», в квестах их нет.

- **Метки.** Именная цель может нести две метки из 39.3. Это исключение из правила «одна метка на группу», потому что цель всегда одна.

- **Здоровье.** У именной цели оно задано в таблице 49.2 вручную, а не по формуле меток: у слабых видов (волк, споровик, лучник) оно поднято, чтобы бой длился 40–90 секунд. Метки меняют поведение и запас оглушения (46.1).

### 49.3 Как проходит охота

1.  **Заказ.** Игрок читает объявление на доске: имя, слух, место, награда. Заказ попадает в журнал, в раздел «Охоты».

2.  **Следы.** В зоне два следа (сломанные ветки, остатки добычи, записка). Каждый показывает направление на карте в круге около 150 м. Логово открывается после двух следов или когда игрок сам к нему подойдёт.

3.  **Бой.** Цель появляется в логове, когда заказ взят. Пока заказа нет, цели в мире нет, поэтому её нельзя убить случайно.

4.  **Награда** выдаётся сразу после победы, возвращаться к доске не нужно (дорога назад короче, 40.1). В бестиарии появляется запись о цели с историей.

### 49.4 Защита от фарма

- Цель не возрождается ни при каких отдыхах. Один и тот же заказ нельзя взять дважды.

- Награды уникальны и скромны: боковые варианты (+8 здоровья, +6 брони), не прибавка к силе.

- В охотах нет условия «убей N обычных врагов по дороге».

- Достижение «Охотник на волков» (убить 50 волков) в 29.1 заменено на «Охотника»: выполнить все 6 охот. В Акте 1 расставлено 18 волков (39.1), остальное до пятидесяти пришлось бы добирать возрождениями и призывами Матери Чащи. Это счётчик убийств, то есть ровно тот фарм, против которого раздел 40.

- Охоты не блокируют сюжет, их можно не брать вообще.

### 49.5 Как писать охоту

- Шаблон: имя, слух на доске (2–3 предложения), два следа с намёками, одна необычная деталь боя, записка с историей цели (3–5 предложений).

- Названия и слухи в этом разделе ИИ-черновик, их нужно заменить своими по правилам раздела 35. Строка добавлена в журнал авторства (35.5).

## 50. Малые системы

### 50.1 Рецепты только из мира

- **Рецепт нельзя купить за золото.** Источники: учит NPC (за доверие, квест, диалог), записка или книга в мире, награда за квест, охоту или босса.

- **Два пути.** У каждого рецепта есть основной и запасной путь, чтобы он не зависел от удачи (40.1).

| **Рецепт**               | **Основной путь**                | **Запасной путь**                     |
|--------------------------|----------------------------------|---------------------------------------|
| Зелье исцеления          | Мара, при первой встрече         | Не нужен, рецепт известен с начала    |
| Зелье выносливости       | Мара, после ночи осады (глава 1) | Записка на мельнице (глава 2)         |
| Противоядие              | Мара, глава 2                    | Страница из «Рецепта Эльзы» (глава 3) |
| Холодное железо (слиток) | Торгрим, глава 1                 | Записка артели в шахте (глава 4)      |
| Настойка против спор     | Квест «Рецепт Эльзы» (40.1)      | Мара при VillageTrust от 70           |
| Масла                    | См. 47.2                         | См. 47.2                              |

- Мара при VillageTrust от 70 учит редким рецептам бесплатно (26.4 исправлено): рецепты не продаются нигде.

- Данные: рецепт это Data Asset (станция, ингредиенты, тег открытия). Получение рецепта ставит Gameplay Tag. Записка-рецепт читается один раз и остаётся в журнале.

### 50.2 Подсказка «что делать дальше»

- Под каждым активным квестом в журнале одна строка с ближайшим шагом, например «Поговорить с Марой в Серой Топи». Это текст, новых маркеров на карте он не добавляет.

- Подсказка называет место, а не ответ. В расследованиях («Чужие следы») она говорит, где продолжить поиски, но не кто виноват. У скрытого квеста «Старый Дуб» подсказки и записи в журнале нет (42.2).

- Переключатель в настройках «Геймплей» («Подсказки журнала»). По умолчанию включён на «Путнике» и «Страже», выключен на «Пепельном». Игрок может изменить его в любой момент, он не привязан к сложности.

- Данные: поле HintText у каждого шага квеста.

### 50.3 Вес и сундук

- **Решение.** Перегруза и штрафов к скорости нет и не будет. Вес считается только у оружия, щитов и брони. У материалов, расходников, масел, записок и квестовых предметов веса нет, но размер стека ограничен (материалы 20, расходники 10).

- **Лимит** = 100 + 3 × Сила (130 на старте). Типичный вес: меч 4, щит 5, топор 6, двуручный меч 9, тряпичный набор 6, кожаный 14, кольчужный 28. Всё снаряжение Акта 1 (шесть оружий, два щита, три набора) весит около 90, то есть упереться в лимит можно только нарочно.

- **Если место закончилось,** подбор отклоняется с подсказкой «Нет места: продайте или оставьте в сундуке». Ничего не пропадает (27.2).

- **Сундук** в доме у очага Серой Топи. 60 слотов, вес не считается, доступен после пролога. Хранить можно всё, кроме квестовых предметов. Перенос идёт атомарной транзакцией между двумя контейнерами (27.2). В MMO это склад аккаунта.

- **Ремень «Стойкость»** (27.1) теперь даёт +20 к лимиту вместо +10.

- Тесты: подбор при заполненном весе отказывает без потерь, перенос в сундук и обратно не дублирует и не теряет предметы (27.4).

### 50.4 Локальный лог смертей

- **Что это.** Файл на компьютере разработчика и тестеров, одна JSON-строка на смерть, в папке Saved/DeathLog. Он нужен, чтобы видеть, где игроки застревают, быстрее, чем догадками. Игроку не показывается и никуда не отправляется (33.7: личные данные не собираются).

- **Что пишется:** время сессии, глава и зона, позиция с точностью до 5 м, ID врага и атаки, убившей героя, уровень героя, сложность, стиль оружия и активное масло, число фляг, время с последнего отдыха, номер смерти подряд на этом месте.

- **Что не пишется:** имя пользователя, пути на диске, любые идентификаторы компьютера.

- **Когда включён.** В сборках разработки и плейтеста включён. В релизной выключен, включается флагом в конфиге у тестера. Файл разработчику отправляют вручную.

- **Как читать.** Скрипт на Python делает три таблицы: места по числу смертей (сетка 10 м), враги и атаки по числу смертей, смерти по главам и уровню героя. Места выше порога из 43.2 (в среднем пять на место) идут в список правок телеграфов и ярлыков.

- **Устройство.** UDeathLogSubsystem (GameInstance Subsystem). События смерти приходят через Gameplay Tags и делегаты, как у достижений (29.1). Интерфейс IDeathLogSink: сейчас запись в файл, для MMO позже серверная аналитика с согласия игрока (33.7).

- **Когда делать.** Уже в этапе A0, чтобы данные шли с первых плейтестов.

# Как поставить «Последний очаг» на телефон (Android)

Игра собирается в файл **LastHearth.apk**: Android 7.1 и новее, ARM64 и ARMv7, горизонтальный экран. Есть два пути. Первый удобнее: настроить один раз, и дальше каждая новая версия сама появляется на странице для скачивания.

## Путь 1. Сборка в облаке GitHub (рекомендуется)

Компьютер нужен только один раз, чтобы получить файл лицензии Unity. Он бесплатный.

**Шаг 1. Файл лицензии Unity (один раз).**
1. Установите [Unity Hub](https://unity.com/download) и войдите в аккаунт Unity (регистрация бесплатная).
2. Unity Hub → значок шестерёнки (Preferences) → **Licenses** → **Add** → **Get a free personal license**. Нажмите именно «Add», даже если лицензия уже видна: только так создаётся файл.
3. Найдите файл `Unity_lic.ulf` (папки скрытые, включите показ скрытых файлов):
   - Windows: `C:\ProgramData\Unity\Unity_lic.ulf`
   - Mac: `/Library/Application Support/Unity/Unity_lic.ulf`
   - Linux: `~/.local/share/unity3d/Unity/Unity_lic.ulf`

**Шаг 2. Три секрета в GitHub (один раз).** Репозиторий на github.com → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**:

| Имя | Значение |
|---|---|
| `UNITY_LICENSE` | всё содержимое файла `Unity_lic.ulf` (откройте блокнотом, скопируйте целиком) |
| `UNITY_EMAIL` | почта аккаунта Unity |
| `UNITY_PASSWORD` | пароль аккаунта Unity |

Секреты видны только сборке, в коде и логах их нет. Если на аккаунте Unity включена двухфакторная защита через приложение, облачный вход может не сработать. Тогда используйте путь 2.

**Шаг 3. Сборка.** Вкладка **Actions** → **Android APK** → **Run workflow**. Дальше она запускается сама при каждом изменении игры. Первая сборка идёт 30–60 минут, следующие быстрее.

**Шаг 4. Установка.** На телефоне откройте страницу **Releases** репозитория (`github.com/<владелец>/<репозиторий>/releases`; если репозиторий закрытый, войдите в GitHub в браузере). В последней сборке нажмите **LastHearth.apk**, затем «Открыть». Android попросит разрешить установку из браузера: «Настройки» → разрешить → назад → «Установить». Если Play Защита предупредит о неизвестном приложении, выберите «Всё равно установить».

## Путь 2. Сборка в Unity на компьютере

1. Unity Hub → **Installs** → **Install Editor** → **Unity 6.3 LTS**, отметьте модуль **Android Build Support** вместе с **OpenJDK** и **Android SDK & NDK Tools**.
2. Hub → **Add** → **Add project from disk** → папка `hearth/unity/LastHearth`, откройте.
3. В меню наверху: **Последний очаг → Собрать APK для телефона**. Через 10–30 минут откроется папка с `Builds/Android/LastHearth.apk`.
4. Перекиньте файл на телефон (кабель, Telegram «Избранное», облако) и установите, как в шаге 4 выше.

Если телефон подключён кабелем с включённой «Отладкой по USB» (Настройки → О телефоне → 7 раз нажать «Номер сборки» → Для разработчиков), можно сразу File → Build Profiles → Android → **Build And Run**.

## Обновления и сохранение

- Новая сборка ставится **поверх старой**, сохранение остаётся. Все тестовые сборки подписаны одним ключом из `hearth/unity/LastHearth/Keystore`.
- Сохранение лежит в данных приложения. **Удаление игры удаляет и сохранение.**
- Тестовый ключ годится только для своих телефонов. Для Google Play нужен отдельный секретный ключ, его не кладут в репозиторий.

## Что на телефоне

- Экран горизонтальный, кнопки крупные, размер подстраивается под плотность экрана, вырез камеры не мешает.
- Список листается пальцем. Кнопка «Назад» закрывает итог боя, возвращает на вкладку «Крепость», а оттуда выходит из игры с сохранением.
- Строка «Что дальше» подсказывает следующий шаг в первые дни.
- Кнопка **«Отладка»** вверху открывает «+1 час», «+8 часов» и «Новая игра», чтобы быстро проверить долгие таймеры.
- Игра сохраняется каждые 30 секунд и при сворачивании. Пока идёт бой или Наплыв, экран не гаснет.

Это тестовая версия: вместо арта пока текстовый экран, а PvP и события играются против «призраков» на устройстве.

# «Последний очаг» в Unity

Вся экономика и все режимы работают и проверены тестами. Есть арт в игрушечном стиле Hustle Castle: разрез крепости с отрендеренными залами, анимированные жители, герои и твари, живой огонь очага, гора с замком, карта кампании, украшения, музыка и звуки (`docs/ART.md`). Кнопки и панели пока простые, без отрисованного интерфейса.

**На телефон:** см. [`hearth/INSTALL.md`](../INSTALL.md) — сборка APK в облаке GitHub или в Unity одной кнопкой меню «Последний очаг → Собрать APK для телефона».

## Как открыть

1. Установите [Unity Hub](https://unity.com/download).
2. В Hub установите **Unity 6.3 LTS** с модулем **Android Build Support**.
3. Hub → **Add** → **Add project from disk** → папка `hearth/unity/LastHearth`. Если Hub предложит другую версию 6.3, соглашайтесь.
4. Откройте любую сцену или создайте пустую (File → New Scene) и нажмите **Play**.

Появится отладочный экран ядра. Крепость живёт в Появится отладочный экран ядра. Крепость живёт в реальном времени и сохраняется сама. При следующем запуске она досчитывает время, пока игры не было; начатый и брошенный бой доигрывается автобоем. Наверху ресурсы и кнопки **«+1 час»**, **«+8 часов»** (прокрутка времени), **«Новая игра»**. Ниже вкладки:

| Вкладка | Что проверить |
|---|---|
| **Крепость** | **разрез крепости** под снежной горой с замком: залы, живой огонь очага, иней на промёрзших залах, жители ходят и работают, герои отдыхают в казарме; нажмите на зал — его дела (собрать, улучшить, поставить жителя, **украсить**), на пустую ячейку — стройка с картинками залов; улучшение очага с правилами (что не хватает), стройка и очередь, «Бесплатно» на последние 5 минут, песочные часы и Искры, залы, промерзание, режимы очага, жители и герои |
| **Бои** | **карта кампании** (10 мест, туман над будущими), бой на сцене: герои и твари с анимациями ударов; кампания (190 боёв, повторы), Охота (с очага 6), Арена (с 16: три соперника, рейтинг, лиги, лавка Славы), Набеги (с 17: флаги, звёзды, месть) |
| **Наплыв** | с 19:00 вечерняя оборона вживую: выберите героя → «Сюда» на этаже, «Вспышка очага», «Люк»; или отдайте автомату |
| **Развитие** | Сердце очага за Жар, специализации залов за Чертежи |
| **Вылазки** | отряд из 1–3 жителей, развилки (надёжный / рискованный / долгий путь), карточки решений по возвращении |
| **Задания и лавки** | поручения дня, четвёртый строитель, наборы ресурсов, лавка Брика |
| **События** | все 7 событий: Долгая ночь, Портал, Турнир, Кладоискатели (гекс-карта), Ярмарка (курсы, заказы), Осада застав (гарнизоны, ловушки, штурм вживую), Праздник очага (фонари) |

## Устройство

| Папка | Что внутри |
|---|---|
| `Assets/LastHearth/Core` | чистое ядро на C# без UnityEngine: детерминированное, всё время передаётся явно, поэтому его можно проверить тестами и позже на сервере |
| `Assets/LastHearth/Core/Combat` | бой с решениями: телеграфы, связки классов, автобой и «аккуратный игрок» для калибровки |
| `Assets/LastHearth/Core/Surge` | Наплыв: твари лезут по этажам разреза к очагу |
| `Assets/LastHearth/Core/Tests~` (Unity пропускает папки с `~`; запуск: `dotnet test hearth/core-tests`) | 94 теста NUnit: экономика, калибровка боя, Наплыва и PvP, события, лавки, бот на 30 дней |
| `Assets/LastHearth/Editor` | сборка APK одной кнопкой: настройки Android (имя, иконка, горизонтальный экран, IL2CPP ARM64 + ARMv7, ключ подписи) и пустая сцена |
| `Assets/LastHearth/Game` | Unity-слой: запуск, сохранение в `persistentDataPath`, отладочный экран (`GameRunner*.cs`, по файлу на группу вкладок) |
| `Assets/LastHearth/Resources/balance.json` | все числа игры. Генерируется `python hearth/tools/economy.py`, руками не правится; CI проверяет, что файл совпадает с моделью |
| `Assets/LastHearth/Resources/Art` | отрендеренный арт: залы, огонь, гора, карта, листы анимаций и портреты, украшения, `Art.json` (`docs/ART.md`, `hearth/tools/art`) |
| `Assets/LastHearth/Resources/Audio` | музыка (синтез, `hearth/tools/audio/music.py`) и звуки Kenney (CC0) |
| `Assets/LastHearth/Resources/combat.json` | числа боя. Правятся руками; тесты калибровки проверяют, что бой остаётся честным |

PvP и события пока играются против «призраков» того же уровня очага: соперники и места в рейтинге считаются на устройстве, пока нет сервера.

# «Последний очаг» в Unity

Этап M1 (`docs/GDD.md`, раздел 16): ядро игры без графики. Ресурсы, залы и работники, стройка с очередью, тепло и промерзание, офлайн-прогресс, правила очага (защита от раша), герои, ускорения, сохранение.

## Как открыть

1. Установите [Unity Hub](https://unity.com/download).
2. В Hub установите **Unity 6.3 LTS** с модулем **Android Build Support**.
3. Hub → **Add** → **Add project from disk** → папка `hearth/unity/LastHearth`. Если Hub предложит другую версию 6.3, соглашайтесь.
4. Откройте любую сцену или создайте пустую (File → New Scene) и нажмите **Play**.

Появится отладочный экран ядра. Крепость живёт в реальном времени и сохраняется сама. При следующем запуске она досчитывает время, пока игры не было. Что можно проверить:

- **«Улучшить очаг»** — с правилами и списком того, чего не хватает;
- стройка, очередь до 3 работ на строителя, кнопка **«Бесплатно»** для последних 5 минут, ускорение песочными часами и Искрами;
- залы: сбор выработки, промерзание далеко от очага и без угля;
- режимы очага;
- жители и герои;
- **«+1 час»** прокручивает время вперёд, **«Новая игра»** начинает заново;
- **Охота** (с 6-го уровня очага): выберите логово и ранг. Бой идёт в реальном времени: жмите умения героев, отвечайте на красные предупреждения о сильных ударах («Отход», «Стена», «Сокрушение») или включите автобой. За звёзды дают Сердцевины, они идут на умения героев;
- героем жителя делает кнопка «Сделать героем» с выбором класса (нужна казарма).

## Тесты

- **В Unity:** Window → General → **Test Runner** → EditMode → Run All. Если пункта нет, добавьте пакет Test Framework (Window → Package Manager → Unity Registry → Test Framework).
- **Без Unity:** `dotnet test hearth/core-tests`. Это тот же код ядра. Тесты запускаются на каждый push в GitHub Actions.

## Устройство

| Папка | Что внутри |
|---|---|
| `Assets/LastHearth/Core` | чистое ядро на C# без UnityEngine: детерминированное, всё время передаётся явно, поэтому его можно проверить тестами и позже на сервере |
| `Assets/LastHearth/Core/Combat` | бой с решениями: телеграфы, связки классов, автобой и «аккуратный игрок» для калибровки |
| `Assets/LastHearth/Core/Tests` | 46 тестов NUnit: экономика, бот первой сессии, Охота и калибровка боя (4 семьи чудовищ × 7 рангов) |
| `Assets/LastHearth/Game` | Unity-слой: запуск, сохранение в `persistentDataPath`, отладочный экран |
| `Assets/LastHearth/Resources/balance.json` | все числа игры. Генерируется `python hearth/tools/economy.py`, руками не правится; CI проверяет, что файл совпадает с моделью |
| `Assets/LastHearth/Resources/combat.json` | числа боя. Правятся руками; тесты калибровки проверяют, что бой остаётся честным |
